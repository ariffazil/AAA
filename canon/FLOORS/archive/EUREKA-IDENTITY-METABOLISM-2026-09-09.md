## The Two Loops

Most AI systems have one loop:

```
Observe → Learn → Update
```

Organisms have two:

```
Learning Loop:
  Observe → Learn → Update

Identity Loop:
  Remain Yourself
```

These run simultaneously. The learning loop changes what you know. The identity loop ensures what you know doesn't change what you are.

## Identity Is Not Stored

SOUL.md, USER.md, lane configs — these are identity STORAGE, not identity.

Identity is:

```
Constraint persistence across time
through repeated selection under constraint.
```

Constitution analogy:
- Written constitution = identity storage
- Millions of decisions obeying it = identity

The document is not the country. The file is not the identity.

Identity exists when the constraint field produces consistent behavior even without the storage medium.
