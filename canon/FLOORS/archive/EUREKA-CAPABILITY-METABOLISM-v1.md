## Four Constitutional Primitives

### 1. ATTENTION_ROUTING

Attention is the scarce resource. Routing is governance of attention.

```
Identity → Intent → Capability → Tool
Sovereign → Witness → Judgment → Action
```

The router is not a token optimizer. It is an Attention Governor.

### 2. MONOTONIC_RECOVERY

When certainty falls, capability access expands. Never shrink capability because confidence fell. Recover monotonically.

```
UNKNOWN → SABAR → Broaden surface → Proceed safely
```

Fail-open = SABAR. Engineering pragmatism meets governance philosophy.

### 3. WITNESS_MAINTENANCE

Health loops are witnesses. Not executors. Governance begins only when findings change future behavior.

```
Registry → Witness → Governance
```

Maintenance sits in Witness until a human or governor acts.

### 4. SCAR_ENGINEERING

Improvement is not a mutation. Improvement is a mutation that survived consequence.

```
Experience → Evaluation → Scar → Future Behavior
```

Autoresearch (propose→test→keep/revert) is scar formation at the code level.
