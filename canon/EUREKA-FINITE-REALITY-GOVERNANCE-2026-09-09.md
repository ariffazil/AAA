## The Five Frontiers

Nineteen open questions compress into five classes. Each class is a variation of one hidden failure.

### Frontier A — Continuity Problem

**Questions:** Sovereign Absence (B), Time-binding across substrate death (L), Constitutional Suicide (N), Genesis Amnesia, Seal-chain head problem

**Teras:** What truly persists?

```
Model dies
Agent dies
Process dies
Session dies
Human dies
```

Yet something must remain. Identity Metabolism gives the formula:

```
Identity = constraint persistence across time
```

But arifOS lacks a **Continuity Doctrine** — the doctrine for when the constraint owner is absent. This is the set-theoretic equivalent of constitutional succession, institutional inheritance, and civilizational memory.

**Coverage:** 19 existing artifacts partially address. Identity Metabolism is the most mature precursor. **Gap: no explicit continuity doctrine for sovereign absence.**

### Frontier B — Plural Sovereignty Problem

**Questions:** Multi-sovereign federation (A), Dunbar multi-sovereignty (M), Genuine otherness (P), Cross-civilizational inference loss

**Teras:** If there are two F13s, who determines who determines?

This is possibly the largest frontier because all of arifOS is built on:

```
single sovereignty
```

while civilization operates on:

```

```

Humans never solved this. They manage it through:

```
Treaty  |  Trade  |  Courts  |  Borders  |  War
```

In arifOS language:

```
Federation ≠ Shared Sovereignty
```

**Coverage:** ZERO existing artifacts. **Complete virgin territory.**

### Frontier C — Epistemic Boundary Problem

**Questions:** Gödel sentence (C), Shadow of shadow (F), Witnessing witnesses (Q), AI interiority

**Teras:** What can the system not know about itself?

All are variations of one problem:

```
Shadow:          What is not seen.
2nd-order shadow: What is not seen about the process of seeing.
Meta-witness:    Who witnesses the witness?
Gödel sentence:  What is true but unprovable from within the system.
```

Compression:

```
Every governor contains an ungovernable region.
```

This is the mature form of Gödel Lock — not as a failure mode but as a structural invariant.

**Coverage:** ZERO direct artifacts. **Complete virgin territory.**

### Frontier D — Moral Economy Problem

**Questions:** Atonement (D), Reciprocity (R), Sacred vs Useful, Dignity under surveillance

**Teras:** Governance after failure?

Most systems focus on:

```
Prevention  |  Verification  |  Refusal
```

But human civilization built additional institutions:

```
Forgiveness  |  Repentance  |  Debt
Gratitude    |  Mercy        |  Honor
```

arifOS has:

```
Receipt  |  Scar  |  Witness
```

But lacks:

```
Reparation Ledger
Constitutional Apology
```

These are not sentimental. They are governance mechanisms that allow a system to recover legitimacy after failure without requiring the failure to not have happened.

**Coverage:** Only Wawabot anthropological surfaces (2 artifacts). **Very thin.**
