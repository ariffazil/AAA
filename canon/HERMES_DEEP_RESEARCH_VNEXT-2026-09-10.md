## The Inversion

**Before:**
```
Research Engine
Query → Search → Synthesis → Report
```

**After:**
```
Reality Navigation System
Question → Possibility Space → Witness Production
→ Re-examinable Artifacts → Shared Reality Objects
→ Judgment → Action
```

**Core principle:** Deep Research is not the search for answers. Deep Research is the production of re-examinable witness objects that map possibility space, preserve contradictions, and allow humans, agents, and institutions to navigate reality together.

**Shortest form:**
```
Information tells us what was found.
Witness tells us what was seen.
Re-examination tells us what survives scrutiny.
Deep Research ends only when reality can be revisited without the researcher.
```

---

## Layer 0: Question Triage

Do not begin research. Begin with classification.

```yaml
QUESTION_TYPE:
  Reality:    What happened?
  Possibility: What could happen?
  Decision:   What should be done?
  Governance: Who should decide?
  Failure:    What could break?
```

Most research fails because all questions are treated equally. Reality questions ≠ Decision questions.

---

## Layer 1: Possibility Cartography

Do not search for answers. Search for possibility space.

```yaml
POSSIBILITY_MAP:
  Path_A:
  Path_B:
  Path_C:
  Path_D:
  Unknown_Paths:
```

**Primary metric:**
```
RCI = explored possibilities / plausible possibilities
```
Not confidence. Coverage.

Before asking "Am I correct?" ask "Have I explored enough?"

---

## Layer 2: Contradiction Harvesting

Most AI seeks supporting evidence. HERMES must seek contradictions.

```yaml
CONTRADICTION_LEDGER:
  Claim:
  Evidence_For:
  Evidence_Against:
  Unknown:
```

Contradictions are highest-value epistemic territory. They indicate where surface reality ≠ decision reality.

## Layer 3: Witness Production

Purpose: Not readable. Re-examinable.

## Layer 4: Re-examination

Most underappreciated layer.

Do not ask "Can this be stored?" Ask "Can this be challenged later?"

```yaml
REEXAMINATION_PROTOCOL:
  What would falsify this?
  What evidence is missing?
  What could change our conclusion?
  Who should challenge it?
```

If artifact cannot be challenged: Archive, not witness.

## Success Criteria

Research is successful when:

- [ ] Humans can understand
- [ ] Agents can consume
- [ ] Conclusions can be challenged
- [ ] Witnesses can be re-examined
- [ ] Contradictions are not hidden
- [ ] Possibility space is explored
- [ ] Decision space is clear
- [ ] Artifacts survive even if researcher disappears

If not: Good Notes. Not Deep Research.

## The Four Possibility Domains

Every research query must be forced through 4 domains:

**Domain A — Truth:** What is known?

**Domain B — Unknown:** What is not known?

**Domain C — Alternative Explanations:** What else could explain this?

**Domain D — Consequences:** If each hypothesis is true, what follows?

---

## Research Completion Index (RCI)

```text
RCI = explored possibilities / plausible possibilities
```

If RCI < 0.3: Research immature
If RCI 0.3–0.7: Partial coverage
If RCI > 0.7: Comprehensive coverage

Research is complete when all layers exist. Not when report is long.

## Research Graph (Storage)

Do not save research as text. Save as graph.

```
Node:
  ├─ Question
  ├─ Claim
  ├─ Evidence
  ├─ Source
  ├─ Assumption
  └─ Risk

Relationship:
  supports / contradicts / depends_on / extends / invalidates
```

When new agent enters, it traverses graph. Not reads 50 pages.
