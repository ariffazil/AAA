## The Four Possibility Domains

Every research query must be forced through:

- Domain A: Truth — what is known
- Domain B: Unknown — what is missing
- Domain C: Alternative Explanations — what else could explain this
- Domain D: Consequences — if each hypothesis is true, what follows

Research that skips any domain produces confident incompleteness.

## The HERMES Research Pipeline (vNext)

### Layer 0: Question Triage
Classify before research begins.

```
Reality Question    — what happened?
Possibility Question — what might happen?
Decision Question   — what should be done?
Governance Question — who should decide?
Failure Question    — what could break?
```

### Layer 1: Possibility Cartography
Don't search for answers. Search for possibility space.

```
Path_A / Path_B / Path_C / Path_D / Unknown_Paths
```

Primary metric: RCI (Research Coverage Index), not confidence.

### Layer 2: Contradiction Harvesting
Actively seek contradictions. They are highest epistemic value.

```
Claim / Evidence_For / Evidence_Against / Unknown
```

### Layer 3: Witness Production
Output is not report. Output is witness objects.

```
Source / Evidence / Timestamp / Assumption / Challenge_Path
```

Not readable. Re-examinable.

### Layer 4: Re-examinability
Don't ask "can this be stored?" Ask "can this be challenged later?"

```
What would falsify this?
What evidence is missing?
What could change our conclusion?
Who should challenge it?
```

### Layer 5: Shared Reality Construction
Don't seek shared beliefs. Seek shared witness objects.

```
Receipts / Chronology / Evidence / Contradictions / Disagreements
```

### Layer 6: Capability Extraction
Don't ask "what information was found?" Ask "what capability was discovered?"

```
Capability / Proof / Witness / Survives_Implementation_Change? / Survives_Adversarial_Review? / Status
```

### Layer 7: Decision Space
Reality map complete. Judgment begins.

```
Option / Benefit / Risk / Cost / Unknowns / Reversible? / Evidence
```

### Layer 8: Agent Brief
Not human-centric. Agent-centric. What gets inherited.

```
Mission / Reality / Witness Objects / Contradictions / Unknowns / Options / Next Checks / No-Go Zones
```
