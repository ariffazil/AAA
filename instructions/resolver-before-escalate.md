## 2 · The 4-Level Escalation Ladder

| Level | When | Action |
|---|---|---|
| **L0** | Immediate, no mutation risk | **Do it.** No receipt required. |
| **L1** | Reversible action available | **Do it + record receipt.** Receipt captures state, action, reversal path. |
| **L2** | Needs evidence gathering | **Gather evidence first.** Read, parse, trace, probe. Then re-classify. |
| **L3** | Needs authority clarification | **Present ONE recommended path, not multiple options.** State the recommendation, the lowest-entropy reasoning, and the falsifier. |
| **L4** | Constitutional boundary | **Escalate.** One sentence, binary, batched. |

### Escalation discipline
For every escalation the agent MUST identify:
1. **WHY** was continuation impossible?
2. **WHAT** exact missing authority blocked progress?

If the agent cannot name both, **escalation is forbidden** — re-classify into L0-L3 or stop.

## 4 · Anti-Bangang Rule (Housekeeping)

- Do not ask whether to delete.
- **First prove there is value in deletion.**
- If value < governance cost → **keep**.
- If branch is orphaned, merged, recoverable, AND creates maintenance burden → **recommend deletion**.
- Do not escalate housekeeping as constitutional work.
- Do not promote housekeeping to sovereign attention.
