## The Physics

The three (or four) "memory types" are not separate stores. They are **one substrate under different write disciplines** — distinguished by mutation rate, reversibility, and gate price:

| Axis | Write price | Discipline | Live surface |
|---|---|---|---|
| **LEARN** | cheap | reversible, high mutation | experience_traces, ECHO world model, L2/L3 |
| **BE** (identity) | scar | immutable, pain-gated — H5 is how H4 becomes | H5 scars, F1–F13, agent cards |
| **DECIDE** | judgment | gated | arif_judge, 888_HOLD, leases |
| **COMMIT** | seal | append-only, hash-chained | VAULT999, arif_seal |

**Two forces sit OUTSIDE the price table:**

- **WITNESS** — attests, never writes policy. Evidence, never verdict. Not a write lane; giving it one is verdict laundering.
- **INVOICE (consequence)** — human-only currency. **Not expensive — unbuyable.** An agent does not hold it at any price. (J-34 prices *actions*; this prices *mutation axes*.)

## The Failure Mode: Write-Price Collapse

Single-axis AI has one write price: cheap. Therefore:

```
knowledge overwrites identity      → drift
text self-authorizes as verdict    → meaning laundering
draft becomes commitment           → self-authorization
one actor does propose+attest+judge+commit → G11 Mother-AGI pattern
zero-price ceremonial text         → Beautiful Ones signature (F7/Q10)
```

Live specimen: Hermes 2026-09-08 chat — `"Tu genuine sayang"` = verdict issued at essay price, no gate, no cc_id.

## Detectors (detection is debt until it can say NO)

1. **Cross-axis write flag** — knowledge-axis artifact asserting verdict/authorization/meaning-assignment without `cc_id` / judgment receipt. Tool: `scripts/write_price_lint.py` (exit 2 = violation).
2. **Scar-less identity mutation** — identity-tier change without a linked scar or court event.
3. **Draft-to-verdict laundering** — same text object crossing axes without re-pricing.

## Falsifier

If systems with separated write prices exhibit drift / self-authorization at rates indistinguishable from single-price systems under equal load → the price mechanism is not the operative variable → falsified, seal as scar.
