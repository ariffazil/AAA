**Forged:** 2026-09-10

## Axiom

Attention is the scarce resource. Routing is governance of attention.

## Canonical Flow

```
Identity → Intent → Capability → Tool
Sovereign → Witness → Judgment → Action
```

## Implementation

The tool router (hermes-tool-router) is not a token optimizer. It is an Attention Governor.

- First-turn classification narrows the live tool surface
- Session-sticky: classify once, keep the surface
- Monotonic recovery: if a needed tool was pruned, add it permanently
- Fail-open: uncertainty = full surface (SABAR at infrastructure level)

## Governance Rule

Route by intent, not by capability. The question is never "what tools exist?" The question is "what does this moment require?"

## Relationship to Existing Doctrine

- Composes with Attention Graph (AAA)
- Implements SABAR at the tool-surface level
- Enforces F2 TRUTH: only relevant evidence enters context
- Reduces entropy: fewer tools = cleaner attention = better decisions
