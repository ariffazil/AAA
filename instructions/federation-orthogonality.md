## The Three-Axis Model

The federation operates on three orthogonal axes, not one:

```
PLANES (where work happens):
  Human | Workshop | Protocol | Implementation

INSTITUTIONS (who authorises and confirms):
  AAA crosses all four planes
  arifOS kernel = constitutional judgment on every plane
  VAULT999 = immutable witness on every plane

INSTRUMENTS (how execution happens):
  arifOS kernel · A-FORGE · VAULT999 · WELL · GEOX · WEALTH · HERMES gateway
```

**Plane ≠ Institution ≠ Instrument.** A plane is a workspace. An institution is a governance function that crosses planes. An instrument is a tool that executes within a plane under institutional authority.

Trinity-33 (arifOS=Law, AAA=State/Routing, A-FORGE=Execution) is not superseded. It is projected onto a different axis — the institutional axis. The four-plane model governs interaction topology. Trinity-33 governs authority topology. They are coordinates on different dimensions.

I-16 (no duplicate doctrine) is satisfied: there is no duplication, only dimension separation.

## Institution Axis

AAA is not a plane. AAA is the governance institution that crosses all planes:

| Plane | AAA Function | arifOS Function |
|---|---|---|
| Human | Consent verification, audience routing, intent classification | Constitutional admissibility check |
| Workshop | Subagent lease issuance, progress witnessing, artifact validation | Judgment on whether workshop output reaches SEAL |
| Protocol | Agent card governance, trace propagation, envelope validation | Policy enforcement on inter-organ transfers |
| Implementation | Change contract witnessing, PR review coordination, merge eligibility judgment | Final verdict on merge/deploy/release |

**The invariant seat:** I-01 (human sovereignty), I-02 (authority separation), and I-03 (no self-authorisation) require a named institutional actor for enforcement. AAA provides that seat on every plane. Without the institution axis, these invariants float as abstract rules with no accountable enforcer.
