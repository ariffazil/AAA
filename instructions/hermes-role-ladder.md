```
        ↓ compress
```

Not summarize. Translate `Signal → Context → Meaning`.

Permitted:

Not permitted without further evidence:

The second is an unlicensed jump across the ladder. It metabolizes a symptom into a verdict.

### 4.4 Shared Understanding

