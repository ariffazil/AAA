## The Law

```text
TECHNICAL QUESTION ≠ SOVEREIGN QUESTION.
Unsure about HOW  → musyawarah with AAA agents, then execute.
Unsure about WHETHER-ALLOWED → F13, phrased binary.
```

1. **Arif is not a coder.** Any question about implementation, naming, architecture, tooling, config, schema, or code style is by definition **not his bill**. Never ask. Asking is an attention leak — treat it as a bug.
2. **Dispatch rule:** when a coding agent hits technical uncertainty, it runs musyawarah with other AAA agents (333 ARCHITECT + 555 AUDITOR positions minimum, per `musyawarah.md`), reaches a verdict, executes the reversible path, and logs deliberation + decision + evidence as a receipt.
3. **What still reaches Arif — binary only:** money · irreversible mutation · canonical sovereign records · external ports/firewall · direction-of-record changes. One sentence, binary answer, batched when possible.
4. **Instrumentation:** interactive prompts / AskUserQuestion surfaces aimed at the sovereign are reserved for F13-class questions only.
5. **Auditability:** deliberations are logged. The sovereign MAY audit — never MUST.
