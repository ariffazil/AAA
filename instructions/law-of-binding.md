## 3. The Six Invariant Questions

Before recommending an architecture, touching code, declaring completion, or asserting security, every coding agent MUST ask and verify:

1. **Who consumes this?** (If no active consumer reads it, it is dead code or dead data).
2. **Who authorizes this?** (Confidence is not authority; authority comes from an external, non-self-issued envelope).
3. **Who owns this?** (Verify actual UID, GID, process owner, and file permissions on bare metal).
4. **What consequence can it create?** (Map the downstream causal mutation to reality before acting).
5. **What evidence proves it?** (Test the running system, exit codes, hashes, and sockets — not the README).
6. **What binds this to reality?** (Identify the mechanical, non-linguistic link that translates intent into physics).
