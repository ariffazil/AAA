enough metabolism."

```
PERMANENT TOOLS  = ENTROPY ACCUMULATION (ΔS > 0 over time)
EPHEMERAL TOOLS  = CAPABILITY METABOLISM  (ΔS ≤ 0 per cycle)
```


### When Does a Tool Become Permanent?

Only when it has proven itself across **5+ independent missions** with:
- success_rate ≥ 0.90
- zero sandbox violations
- multi-model consensus on safety
- F13 SOVEREIGN ratification

Until then: **IT IS EPHEMERAL. It lives. It works. It dissolves.**
