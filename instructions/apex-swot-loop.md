## The Law

A single agent may not be its own subject, scorer, witness, and judge. A self-SWOT that one
agent scores and then halts at "PENDING" is **self-certification followed by distributed
deadlock** — both are the exact defects this loop exists to prevent.

```
PRODUCED  (self-description)   ≠  MEASURED  (canonical G)
MEASURED                       ≠  VERIFIED  (independent falsification)
VERIFIED                       ≠  WITNESSED (external observation)
WITNESSED                      ≠  JUDGED    (constitutional verdict)
JUDGED                         ≠  SEALED    (F13 + VAULT999 only)
```

## Five Rules

1. **One seat, one role.** No agent fills more than one of {subject, verifier, judge}.
2. **G-space only.** G comes from `forge_evaluate`. A self-estimate is J-space self-report →
   label it ESTIMATED, inadmissible as constitutional G (HARAM: mixing G-space and J-space).
3. **W³ measured, not asserted.** ∛(Human×AI×External): Human = Arif, AI = 555-ASI (NOT the
   subject), External = FRAME. Zero in any channel collapses to DIVERGENT. "CONSENSUS trending"
   without actually invoking the channels is fabrication.
4. **The loop closes, or it is a fault.** PENDING without an owner + deadline =
   SYNCHRONIZATION_FAULT. Route to the next seat; never halt at an open gate.
5. **Declare the evidence ceiling.** A SWOT run with degraded tools (MCP down) is memory-only;
   state it, never present it as probe-grounded. Fix degradation first, or downgrade the claim.

## Capability-Claim Ladder (the P axis, made measurable)

A capability is not a Boolean. "560 skills registered" ≠ "560 capabilities available." Each
state is distinct, and **no claim may outrun the state it actually reached**:

```
DECLARED → RESOLVED → STARTED → HANDSHAKEN → TOOL_LISTED → AUTHORIZED → EXECUTABLE → WITNESSED
        ↘ DEGRADED (stalled at any stage)     ↘ QUARANTINED (failed + isolated)
```

- **DECLARED** — named in config/registry; no proof it resolves.
- **RESOLVED** — executable path / env / transport actually found on disk.
- **STARTED** — process launched; no handshake yet.
- **HANDSHAKEN** — `initialize` succeeded; stdio stream clean (no banner / log pollution).
- **TOOL_LISTED** — tools/resources enumerated by the client.
- **AUTHORIZED** — token/env present and accepted (value redacted, never logged).
- **EXECUTABLE** — one harmless read-only call returned a correct result.
- **WITNESSED** — a second, independent seat observed the result.

**Rule:** a capability claim cites the stage reached + the evidence for it. "Running", "live",
"available", or a bare count without a fresh observation = **UNVERIFIED**. A degraded dependency
caps every claim that depends on it.
