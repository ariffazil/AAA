## The 6 Missing Foundational Laws

### 1. Value Precedes Attention (Value → Attention)
Attention is never random or raw. Value is the pre-filter shaped by purpose, survival, and sovereign mandate. We do not attend to everything; we attend only to what our value function deems worth noticing.

### 2. Attention Has a Real Cost (Attention Budget)
Attention is not an unlimited engine; it is a scarce, expensive fuel. Every token allocated to process noise starves essential computation. Agents must declare explicit `attention_budget` and `ignore_scope`.

### 3. Salience Decay & The Untagging Feature (Decay > Accumulation)
Forgetting stale noise is a constitutional feature, not a bug ($\Delta S \le 0$). Storing without untagging creates memory clutter and decision paralysis. Untagged background decay keeps the hot cache sharp.

### 4. Reality Compression & Identity Tokens (Many → One)
The brain and the kernel do not store raw data streams. They synthesize 1,000 observations into a single discrete identity token (`MRT_KLCC_GUY`, `BASIN_UNDERCHARGED`, `BEKOK_DEEP_1`). Memory stores pointers with metadata, not endless raw transcripts.

### 5. Shared Reality > Shared Attention (Coexistence as Base Layer)
Coexistence in shared time and space is the fundamental base layer ($L0$). Recursive mutual modeling is an expensive premium layer ($L1\text{--}L3$). Stable relationships and robust systems anchor on repeated shared reality, not frantic mutual attention.

### 6. The Witness Function (VAULT999 Continuity)
VAULT999 is primarily a Witness System, not an aggressive judge. It exists to provide immutable continuity proof—anchoring that reality happened, actions were executed, and state transitions were witnessed.
