# capability-gate

> "Tambah capability hanya jika ia mengurangkan beban governance."

## The Meta-Gate (above all gates)

Before adding ANY new capability, agent, organ, or gate:

1. Does this reduce governance burden for existing agents and the human?
2. Does this increase signal-to-metabolism ratio?
3. Would removing this after adding it cause more harm than not having it?

If any answer is NO → HOLD.

This gate sits above F1–F13. It is not a floor — it is a filter.
