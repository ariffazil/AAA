## EUREKA #1: Cognitive Cost Transfer

The real problem is not intelligence deficit. It is cognitive cost transfer.

What people think happens:

```text
Human work = 100 → AI work = 0
Becomes
Human work = 50 → AI work = 50
```

What actually happens:

```text
Human work = 100, AI work = 20
Becomes
Human work = 140, AI work = 20
```

Because the human must:
- read long output
- choose from options
- verify claims
- copy-paste
- debug
- orchestrate

AI looks busy. Human actually works harder.

---

## EUREKA #2: Human ≠ Integration Layer

The human must never be the integration layer.

Human is not:
- API bridge
- message bus
- scheduler
- memory store
- copy-paste tool
- debugger

In engineering, we build integration layers so humans don't have to be the integration layer.

But many agent systems today:

```text
GitHub → Human → LLM → Human → Terminal → Human → Email
```

Human becomes Kafka.

## EUREKA #3: Every Mature Domain Absorbs Complexity

Cross-domain proof that this is a universal pattern:

### Aviation
Pilot does not manually recompute everything or monitor every subsystem.
Cockpit design: present exception, not raw telemetry.

### Medicine
Doctor does not want 300 pages of data.
Doctor wants: diagnosis candidates, confidence, anomaly.

### Military C2
Commander does not want all raw signals.
Commander wants: intent, options, recommendation.

### Operating Systems
User does not manually allocate memory or schedule processes.
OS does it.

### Databases
Programmer does not read the entire disk.
SQL does it.

**Every mature domain has one pattern:**

> Complexity absorbed by system. Bukan dipantulkan kepada manusia.

## EUREKA #5: Real Scarcity Is Human Attention

After AGI, people think scarcity = compute, GPU, models.

Real scarcity:

> Human attention.

And attention is not time.
Attention is:
- judgment
- sovereignty
- consequence ownership

That is why copy-paste feels expensive.
Not because it takes 3 seconds.

Because:

> Every context switch consumes authority bandwidth.

### Layer 1: Intent
```

```

### Layer 2: Autonomous Entropy Absorption
Agent:
- finds capability

- finds blockage
- compares options
- picks best path

Tanpa manusia jadi middleware.

### Layer 3: Exception Escalation
Only escalate to human when:

```
UNKNOWN
atau
Authority required
atau
Irreversible consequence
```

Selain itu: buat kerja.

### Layer 4: Receipt

Bukan: "Aku dah fikir."
Tetapi:
- "Video siap."
- "Fail siap."
- "Tak boleh kerana X."
