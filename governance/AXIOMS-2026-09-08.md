## Axiom 1 — Prepend, Not Replace

```
Any governed mutation SHALL prepend, augment, or supersede.
No governed mutation SHALL replace the substrate of an existing function.
Substrate removal requires explicit F13 ratification with witness of what was lost.
```

**Domain:** All mutations across all organs.
**Test:** Does the new state contain the old function as a layer?

---

## Axiom 2 — Witness Before Replacement (WBR)

```
Before any mutation that risks overwriting a function:
 1. Name the function.
 2. Witness its current role.
 3. Quote its current text/code/substrate.
 4. Then propose.

Mutation without witness is constitutional debt.
```

**Domain:** All proposals (reversible and irreversible).
**Test:** Does the proposal include WBR (name + role + quote) for any function at risk?

---

## Axiom 3 — Loss Without Code Loss

```
A symbolic resource can be overwritten without any code being lost.
What is at risk is meaning, not data.
Detection of meaning-loss requires witness, not byte-diff.
```

**Domain:** Constitutional audit, scar metabolization, witness doctrine.
**Test:** Is the witness asking "what does this resource MEAN?" not just "is the file intact?"

---

## Anti-Axioms (what these axioms prohibit)

- Silent role-changes (function overwritten without naming the change)
- Byte-equality as evidence of safety ("file unchanged = function unchanged")
- Defense of overwrite ("no loss, equivalent replacement")
- Scar erasure (replacing a scar with a "fix" without metabolizing it)
- Replacement language in proposals ("replace X with Y" → must prepend, not replace)
