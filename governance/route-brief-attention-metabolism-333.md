## 4. FALSIFIERS (hard, testable)

These are the conditions under which the doctrine is VOID, not merely "weakened."

### F1 — Sovereignty stability test

> **Falsifier:** F13 SOVEREIGN retains coherent sovereignty for 90 consecutive days without invoking any preference-hierarchy mechanism.

**If TRUE:** The four layers are not nested; they are orthogonal. → Redefine as 2-axis model (withdrawal-cost × identity-coupling) instead of 1-axis ladder.

**If FALSE:** Layers hold as nested. (Note: falsification may take months; consider it a *standing* falsifier, not one to run today.)

> **Falsifier:** A federation run with the pattern active produces outcomes *indistinguishable* from a federation run without the pattern, measured over 100+ consequence-allocation events.

**If TRUE:** "Emergent wisdom" is not detectable. Either the pattern is inert, or its effects are masked by other variables. → Q1 fails. Brief is VOID.

**If FALSE:** Measurable difference exists. Pattern produces something. (Difference itself is not yet wisdom — see F4.)

### F4 — Wisdom definition test

> **Falsifier:** When asked "what is wisdom?" the federation cannot produce a definition that satisfies all three: (a) operationally testable, (b) distinct from intelligence + governance + agency, (c) consistent with BIJAKSANA's existing audit criteria.

**If TRUE:** "Wisdom" was a placeholder word, not a primitive. → Drop "emergent wisdom" framing. Re-route the pattern as "preference-hierarchy-mediated consequence allocation" — a coordination mechanism, not a wisdom claim.

**If FALSE:** Wisdom has a defensible definition. Pattern continues.

### F5 — Purpose Continuation Test survival

> **Falsifier:** PCT, when run per-consequence-allocation, produces HOLD on more than 50% of consequences in a 30-day window.

**If TRUE:** PCT is too strict; the federation cannot function. → Re-tune threshold OR reduce PCT to only consequence categories where it adds signal (not all).

**If FALSE:** PCT is well-calibrated. Pattern holds.
