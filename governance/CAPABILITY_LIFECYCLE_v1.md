# Capability Lifecycle Doctrine

## One Law

Capability lives because reality keeps paying for it — not because it was once created.

## Three Levels of Intelligence

| Level | Question | Industry status | arifOS status |
|-------|----------|-----------------|---------------|
| 1. GENERATE | Can the system produce? | Over-measured (benchmarks) | Mature |
| 2. GOVERN | What SHOULD be done? | Rare | Mature (F1-F13, 333/555/888, judge→forge→seal) |
| 3. EVOLVE | How does the system change over time? | Almost unmapped | PARTIAL — this doctrine closes it |

## The Evolution Unit

Not the agent (too big). Not memory (passive). Not skill (implementation-specific).
The evolution unit is **capability** — it can transfer bodies, combine, be inherited, be retired, independent of its original host.

Like genes across organisms: capabilities move across agents, models, runtimes.

## Lifecycle (the chain)

Experience → Classify → Promote → Persist → Witness → Compete for attention → Retire

Break points observed in arifOS (2026-09-06 audit trigger):
- Hermes fast lane: promotion boundary = F13 alone. Scales to ~150 skills, breaks at ~500.
- Extinction engine: exists for ephemeral tools (forge_ephemeral retire), NOT for skills.
- Witness: formal for tools (forge_witness W³), NOT yet for skill usage.
- Trusted attention: skill index growth dilutes routing signal. No allocation primitive yet.

## Four Skill Classes (auditor taxonomy)

- ALIVE: used + recent + witnessed → keep
- DORMANT: correct + unused → archive
- ZOMBIE: unused + unwitnessed + no provenance → kill candidate
- GHOST: exists but no one knows why/when/what outcome → most dangerous, looks like capability, is actually historical artifact

## Drift = gap between what a skill claims and what reality shows

Five kinds: reality drift (world changed), usage drift (nobody calls it), outcome drift (called but overridden/fixed), semantic drift (name same, meaning moved), provenance drift (witness forgotten).

## Legitimacy

"Arif believes" works at 150 skills. At 5000 it doesn't. Capability legitimacy must become gradient, not binary: Witnessed > Self-Witnessed > Unwitnessed.

## Binding Rules

1. Author ≠ Auditor. An auditor that mutates the audited is VOID.
2. No skill survives on existence alone. Survival = Usage + Success + Witness + Freshness − Collision − Dead References.
3. Safety-relevant + self-witnessed → quarantine until second witness.
4. Governance is a capability (an organ), not an external brake.
5. Creation without extinction is bureaucracy formation. The kill path is constitutional, not optional.

## What this doctrine does NOT do

It does not grant A-FORGE or any agent authority to delete skills unilaterally. Death penalty for Hermes skills remains F13 + auditor evidence. The auditor proposes; Arif disposes.
