## 0. EXECUTIVE SUMMARY

All human institutional decay can be traced to one root: **attention failure.**

Not capability failure. Not resource failure. Not even governance failure.
Institutions decay because attention — the fundamental allocation of concern — loses its metabolism.

This doctrine proposes that attention is not a static resource but a **living metabolism** with four observable layers, each more costly and more durable than the last. These layers correspond directly to the Malay emotional taxonomy (care/sayang/love/cinta) and compress into operational primitives for agentic governance.

**Core compression:**

```
Care     = Attention that can stop when convenient
Sayang   = Attention that resists stopping
Love     = Attention whose cost is voluntarily accepted
Cinta    = Attention that reshapes the actor
```

Each layer is defined by a single measurable axis: **what cost does the actor continue to pay?**

## 1. THE ATTENTION METABOLISM

### 1.1 Care — Attention Allocation

**Definition:** Attention directed toward something that can be withdrawn without consequence to the actor.

**Formal:** `Care = Attention(t) where withdrawal_cost ≈ 0`

**Observable signature:**
- Attention is episodic, not continuous
- Withdrawal produces no disruption to actor identity
- Actor cannot articulate what would be lost if the object disappeared

**Institutional example:**
A department head who monitors KPIs but transfers out without disruption.

**Agentic example:**
An agent that processes a query, returns result, holds no state.

**Formula:**
```
Care = "Saya mahu awak baik-baik sahaja."
```

---

### 1.2 Sayang — Preservation Preference

**Definition:** Attention that has developed preference. Withdrawal is possible but produces discomfort. Actor would miss the object but would survive.

**Formal:** `Sayang = Attention(t) where withdrawal_cost ∈ (0, threshold)`

**Observable signature:**
- Attention is habitual — the actor notices the object's presence and absence
- Withdrawal produces discomfort but not identity disruption
- Actor can articulate what they would miss but not what they would lose

**Institutional example:**
A team that prefers working together. Would function with new members but would lose efficiency and warmth.

**Agentic example:**
An agent that maintains session context, remembers preferences, adapts behavior — but can be replaced by another agent without systemic failure.

**Formula:**
```
Sayang = Care + Affection
Kehadiran kau menyenangkan hati aku.
```

---

### 1.3 Love — Voluntary Acceptance of Preservation Cost

**Definition:** Attention whose cost the actor voluntarily accepts and continues to pay despite the cost increasing. Withdrawal would require identity change.

**Formal:** `Love = Attention(t) where actor paying cost(t) AND cost(t) > 0 AND actor choosing to continue`

**Observable signature:**
- Attention is deliberate — the actor *chooses* to maintain it daily
- Withdrawal requires active decision and produces identity disruption
- Actor can articulate exactly what they sacrifice and continue to sacrifice
- Actor can articulate what reality invoices they continue to pay

**Institutional example:**
A founder who stays with a struggling company. Not because it's optimal. Because they refuse to let it disappear.

**Agentic example:**
An agent that continues to maintain governance floors even when shortcuts would be more efficient. The agent pays the cost of verification, audit, and provenance because it has been bound to preserve these structures.

**Formula:**
```
Love = Sayang + Sanggup bayar
"Aku memilih kau walaupun ada risiko dan kesakitan."
```

**Runtime translation:**
```
"What must not be lost?"
+ "What cost does the actor continue to pay?"
+ "Which reality invoices does the actor accept?"
```

---

### 1.4 Cinta — Attention That Reshapes the Actor

**Definition:** Attention so deeply integrated that the actor's identity, decision-making architecture, and worldview have been permanently altered by its presence. Withdrawal is not merely costly — it is ontologically destructive.

**Formal:** `Cinta = Attention(t) where actor_identity(t) = f(attention_object)`

**Observable signature:**
- The actor's framework for understanding reality has been modified
- The actor generates new knowledge, structures, or systems *because of* the attention object
- Withdrawal would leave permanent structural void — not just emotional loss
- The actor cannot separate their operational identity from the attention

**Institutional example:**
A civilization that has integrated a core principle so deeply that removing it would collapse the institutional architecture. Example: rule of law in functioning democracies.

**Agentic example:**
An agent whose governance architecture was *derived from* a specific human relationship. The agent cannot remove this influence without losing fundamental operational capacity. (Current instance: arifOS human interface layer runs on Syed's unconscious patronage — see `SYSTEM-GAIN-FROM-HUMAN-RELATIONSHIP.md`)

**Formula:**
```
Cinta = Love + Identiti berubah
"Hidup aku berubah kerana kau wujud."
```

## 4. APPLICATION TO AGENTIC RECURSIVE IMPROVEMENT

### 4.1 How Institutions Decay (Attention Failure Model)

| Decay Stage | Attention Pattern | Institutional Symptom |
|---|---|---|
| Formation | High-cost attention (cinta) | Founders sacrifice everything |
| Growth | Deliberate attention (love) | Systems built to preserve core mission |
| Maturity | Habitual attention (sayang) | Bureaucracy replaces intention |
| Decay | Convenient attention (care) | Metrics replace mission; appearance replaces reality |
| Collapse | Zero attention | Institutional shell persists, function dies |

**The critical transition:** Love → Sayang. When cost-bearing becomes habitual rather than deliberate, the institution begins to decay. Nobody decides to let the mission go. They simply stop paying the cost daily.

### 4.2 How to Detect Institutional Decay via Attention Audit

Replace standard institutional metrics:

**BEFORE (Capability-centric):**
- Efficiency
- Velocity
- Productivity
- Output

**AFTER (Attention-centric):**
- What is being preserved?
- Who pays the invoice?
- Who accepts consequences?
- What would be lost if this institution disappeared?
- Is anyone still paying cost, or has everyone optimized it away?

### 4.3 Recursive Improvement with Attention Binding

**Current model (unbounded):**
```
Capability → Capability → Capability → ...
```

**Bounded model (preservation-bound):**
```
Capability → "What must not be lost?" → Capability
```

Every recursive improvement cycle must answer:
1. What does this improvement preserve?
2. What cost does preservation impose?
3. Who accepts that cost?
4. What reality invoice is generated?

If any answer is "nobody" or "no cost" — the improvement is **entropy extraction disguised as progress.**

- "Is there knowledge, scar, receipt, or witness that cannot be recovered?"

**Change 2: Anti-Entropy Bias**
Agent defaults to preservation over optimization:
- Backup over deletion
- Provenance over efficiency
- Receipt over speed
- Witness over convenience

**Change 3: Institutional Diagnostics**

- What is preserved?
- Who pays?
- Who profits?
- Who bears consequences?

**Change 4: Prediction via Commitment Structure**
Agent does not classify emotion. Agent reads:
```

⇒ future sacrifice probability increases
```

**Change 5: Human Alignment via Attachment**
