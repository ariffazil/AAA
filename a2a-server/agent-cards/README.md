# AAA A2A Canonical Agent Cards

> **Canonical Source of Truth** for AAA A2A Federation Agent Cards.
> Schema Version: `arifOS/agent-card/v2.2.0`
> Protocol: A2A / JSON-RPC / REST Gateway

## Structure

- `identity/`: Sovereign Identity Cores (333-AGI, 555-ASI, 888-APEX, i-ARIF)
- `organs/`: Federation Organs (aforge, arifos, geox, wealth, well)
- `harnesses/`: FI Warga Harnesses (antigravity, claude-code, codex, kimi-code, openclaw, opencode, qwen-code, grok-build, etc.)
- `extensions/`: Ecosystem extensions & adapters
- `roles/`: Federation operational roles
- `forge/`: Actuator & builder profiles
