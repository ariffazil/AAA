## E-01 :: Spawn Transfers Work, Never Authority

Authority stays at the constitutional center. Work flows to the rim. Subagents are temporary witnesses, not power holders.

## E-02 :: The Bottleneck Is Not Intelligence

Most systems can think. Few can verify. Very few can judge. The scarcity is 555 and 888, not 333.

## E-03 :: Every Spawn Creates Debt

No spawn is free. Every spawn adds coordination, verification, judgment, or provenance debt. Spawn is valid only when expected_entropy_reduction > expected_debt.

## E-04 :: Governance Is Measured Per Spawn

Not per task. Not per session. Per spawn — because debt happens at spawn.

## E-05 :: Parallelism Is Not The Enemy

Many workers is fine. Unbounded topology is the killer. Flat tree (P → A, B, C) is controlled. Recursive nesting is where governance dies.

## E-06 :: No-Nesting Is Not Anti-Loop

It is anti-diseconomy. The goal is to preserve verification capacity, not stop recursion for its own sake.

## E-07 :: The Real Dunbar Boundary

Not number_of_agents. Not number_of_subagents. **maximum_receipt_chain_depth** — the longest chain a human can verify end-to-end. That is the federation's limit.

## E-08 :: Aggregate Is For Dashboard

Per-spawn = audit. Aggregate = visualization. Never audit from aggregate.

## E-09 :: Intelligence Is Not The Same As Governance

A system can be very smart and very unsafe. Governance is a separate dimension.

## E-10 :: Unknown Is A Valid Answer

If a system cannot say UNKNOWN, it will hallucinate. [UNKNOWN] is constitutional function, not failure.

## E-11 :: Enforcement That Depends On Memory Has Already Failed

Runtime > Memory. Mechanism > Intention. "Usually", "normally", "mostly" are governance failure modes.

## E-12 :: Capability Beats Instruction

"Don't do X" is weak. "Cannot do X" is strong. Governance lives in capability, not advice.

## E-13 :: Institutional Failure Is Authority Drift

When everyone follows the boss and no one follows reality, the institution has failed.

## E-14 :: Humans And Agents Fail The Same Way

## E-15 :: Consensus Is Not The Goal

AAA optimizes productive disagreement, not agreement. Information lives where views diverge.

## E-16 :: The Strongest Worker Is The One That Challenges

A worker that says "correct" has no value. A worker that says "this assumption may be wrong" is the most valuable.

## E-17 :: Provenance Debt Is The Silent Debt

Verification debt explodes today. Judgment debt explodes next week. Provenance debt explodes five years from now. The most expensive question: "Where did this come from?"

Memory can lie. Receipts can be audited. Federations survive on receipts, not on memory.

## E-19 :: Infrastructure Failure ≠ Governance Failure

Vault down is infrastructure issue, not constitutional violation. Do not mix the two.
