## What Each Component Actually Does

### arifOS (Kernel)
The law. 7 verbs: init → observe → think → route → judge → seal. Every action goes through F1-F13 constitutional floors. 48 stars = most visible component.

### AAA (Surface)
The cockpit. React 19 dashboard showing all agents live. A2A protocol gateway. Agent registry (11 FI instruments). Task router. Where humans see the federation.

### A-FORGE (Hands)
Execution shell. 119 MCP tools. If arifOS says SEAL, A-FORGE does the work — deploy, code, shell, browser, data ops. The "hands" that touch reality.

### GEOX (Earth)
Geological intelligence. 30 MCP tools covering well logs, petrophysics, seismic, basin evaluation, prospect risk. Domain-specific to earth sciences. The most technically deep organ — 64k files, 3.2GB.

### WEALTH (Capital)
Economic truth lane. 11 MCP tools. Capital allocation, NPV, reward modeling, entropy pricing. Prices decisions before APEX judges them.

### WELL (Mirror)
Biometric + machine readiness. 35 MCP tools. Monitors human vitality, machine health, governance coherence, and coupled risk. "The mirror never commands."
