# RRR — Resource Reality Resolution (111 SENSE)

RRR names what `arif_observe` already does: establish the minimum reality set
BEFORE interpretation begins. Verb-first: `arif_observe(mode="rrr", query=<intent>)`.
Convenience surface: `arifos://rrr/{intent}` (rrr/v1.0) — same resolver.

**Doctrine:** RRR discovers. RRR does not think. RRR does not judge.
Reality chooses the skill. The skill should not choose reality.
