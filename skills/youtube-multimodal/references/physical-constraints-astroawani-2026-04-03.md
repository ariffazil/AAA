## Doom Loop Identified

```
Extract dividends for subsidies
    → Starve upstream capex
        → Production declines faster
            → Import more crude at premium
                → Subsidy burden increases
                    → Extract more dividends
                        → [LOOP]
```

This is a self-reinforcing negative cycle. Each iteration deepens import
dependency and weakens domestic production capacity.
