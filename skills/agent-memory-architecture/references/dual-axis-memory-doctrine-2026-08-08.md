## Technical pitfall: render-agents.sh fragment list

Adding a new fragment to `/root/AAA/instructions/<name>.md` does NOT cause it to appear in AGENTS.md/CLAUDE.md. The fragment list in `/root/scripts/render-agents.sh` `render_one` calls must be manually edited AND the script re-run. Verify with `grep -c "<phrase from new fragment>" /root/AGENTS.md` after render. Without this check, "the doctrine was rendered" can be false while still printing "✅ AGENTS.md: rendered (N fragments)" — the count goes up only if the fragment is named in `render_one`.
