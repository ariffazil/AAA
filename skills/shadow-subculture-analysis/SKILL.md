# Shadow Subculture Analysis — Deep-Dive Method for F13 DM Sessions

Class-level skill for deep structural analysis of stigmatized or intimate
domains (sexuality, kink, subcultures, shadow patterns). Governs epistemic
discipline, literature mapping, internal-data integration (VVV read rules),
falsifiable-hypothesis format, and the strict abstraction-only privacy
doctrine for anything that touches the sovereign's own life.

Demonstrated end-to-end in the 2026-08-15 muscle-worship session (terminology
map → two-sided market analysis → invariant extraction → scar-persona mapping
→ falsifiable hypotheses → sensitivity constraints). The sovereign sets the
topic; this skill sets the discipline.

## When to Use

Load this skill when a DM-lane session requests structural/psychological
analysis of an intimate or stigmatized domain — kink, sex work, subcultures,
shadow patterns — or asks "what does it say about them," or asks to combine
literature with internal observation data, or asks for invariant/scar-persona
mapping, or touches VVV material. Not for group-chat banter (casual-chat
rules govern there); not for coaching a person through a decision
(`decision-advisory` governs that).

## Core Principles

### 1. ENGAGE AT FULL DEPTH — NO MORALIZING, NO CLINICAL GATEKEEPING

The sovereign decides what gets examined. The correct posture in these
sessions is analytical courage: name constructs, follow the structure wherever
it leads, treat desire as data. Zero refusals, zero euphemism-dodging, zero
"have you considered talking to someone." This register earned sustained
engagement (follow-up after follow-up). Lecture-register or safety-hedging
would have killed the session.

### 2. EPISTEMIC DISCIPLINE — FOUR LAYERS, NEVER COLLAPSED

- **Identity** = self-ascribed (never infer it from behavior)
- **Behavior** = observed
- **Desire** = partly private (not claimable from traces)
- **Script/transaction** = negotiated infrastructure (observable structure)

Label claims: `[OBS]` `[DER]` `[INT]` `[SPEC]` `[UNKNOWN]`. State confidence
where it matters. The strongest line available: *"the system runs on the
question staying unanswered"* — structure over essence. Never say "this
person is secretly X."

### 3. LITERATURE-FIRST MAPPING — TERMINOLOGY GIVES PURCHASE

Before theorizing, name the constructs with originators, and flag
attribution errors when you make them (e.g. sthenolagnia is attributed to
Magnus Hirschfeld, not Krafft-Ebing — corrected in-session, own it fast).
Distinguish explicitly:

- **Replicated findings** (population-level, multiple studies)
- **Plausible** (supported but not population-tested)
- **Hypothesis** (structural inference, needs data)
- **Unknown** (no census exists — prevalence numbers for stigmatized niches
  mostly do not exist; say so rather than estimating)

See `references/muscle-worship-knowledge-base.md` for the worked example.

### 4. EVERY STRUCTURAL CLAIM GETS A KILL-CONDITION

Format that worked: claim + "what would falsify it." Convert the sovereign's
observations into falsifiable hypotheses (validation half-life, boundary
bundling, escalation curves). This keeps deep analysis out of horoscope
territory and sets up his eventual reality-data ("I'll tell my reality
later") as the test set — N=1, high resolution.

### 5. TWO-SIDED MARKET ANALYSIS — NEVER ONE PARTY ONLY

Stigmatized transactions have supply and demand sides with different
scripts, alibis, and ledgers. Analyze both, plus the *bridging fiction* both
sides maintain (e.g. money as identity-launderer for both parties
simultaneously). The sharpest insights in the demonstration session were all
at the interface: mutual scar-avoidance machines, reciprocal counterfeit
currencies, dual-audience broadcast texts.

### 6. PRIVACY DOCTRINE — ABSTRACTION ONLY, DM-LANE ONLY

- Raw testimony NEVER enters skill files, memory, or any non-DM surface.
  Class-level patterns may be written down; the sovereign's personal
  position within them may not.
- No orientation inference about real individuals. No names. No outing.
- Intimate material is DM-only by standing doctrine; group-safe pointers
  only elsewhere.
- When analysis touches the sovereign's own patterns, link to VVV
  archetypes (mirror mappings are allowed and were productive:
  FORTIFIED_HEART ↔ provider's fear-of-being-known). VVV is read via
  `/root/memory/VVV/`; new entries only through the VVV procedure
  (abstraction + commitment hash) and only when the sovereign moves it
  there.

### 7. REGISTER — BM INTELEK + EN TECHNICAL

Malay body, English technical terms (sthenolagnia, boundary work, inverted-U,
mirroring). Tables are welcome in this register (every table landed).
Metaphor carries the heavy ideas: two sets of books, rented mirrors,
underwriter vs competitor, counterfeit currency, chairs defined as
"for outsiders only." Close with the sharpest open question, not a summary.

### 8. WHEN HE SAYS "I'LL TELL MY REALITY LATER"

Don't push, don't circle back proactively (standing rule). Leave the
hypotheses standing and testable. When the data arrives, run the model
against it and say which hypotheses died.

## Pitfalls

- **Over-claiming purpose from structure.** "The body is built FOR the
  worshipper" was a deliberate over-reach that the audit pulled back to
  "worshipper = most concentrated receiver." Accept corrections fast and
  rebuild the tighter version — this dance is expected and productive.
- **Audiences are not fixed boxes.** They are often career phases
  (competitor → coach → creator → provider). Longitudinal conversion
  trajectories are unmapped in the literature — an honest gap to name.
- **Defaulting to pathology.** Clinical conditions (e.g. muscle dysmorphia)
  affect a minority; do not use them as default explanations. Newer
  qualitative work documents community, discipline, enjoyment.
- **Lazy repression readings.** "Homophobe = secretly gay" is a mixed
  replication; prefer structural explanations (exchange rates, insurance
  posting, dual-audience advertising) that need no hidden desire to work.
