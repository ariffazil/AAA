# Know-Pragmatics — Practical Substrate

Theory optimizes. Pragmatics survives.

The cheapest reversible action beats the theoretically optimal irreversible one.

## Use when
- Choosing between perfect-but-slow and good-enough-now
- Deciding whether to fix a defect or document it
- Estimating effort vs value for a task
- Recognizing when an exception has eaten a rule
- Saying "this is the answer" vs "this is the doctrine"

## Don't use for
- Engineering sizing (use FORGE)
- Pure theory (use know-math/know-physics)
- Doctrinal questions (use governance)
