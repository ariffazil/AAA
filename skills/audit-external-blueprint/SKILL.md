# Audit External Blueprint / Frontier-Model Report

Bila Arif tampal laporan arkitek luar (Gemini/Claude/blueprint PDF) untuk audit: jangan terima, jangan tolak menyeluruh. Ground claim-by-claim lawan host hidup.

## Aliran (terbukti 29 Okt atas audit blueprint ASI)

1. **Probe dulu, nilai kemudian.** Setiap dakwaan fakta: path fail wujud? angka match? kod semasa vs snapshot? Label BETUL / SALAH(lapuk|reka) / SEPARUH / UNKNOWN / UNRECONCILED.
2. **Dakwaan 'defect dah dibetulkan' mesti semak tarikh.** Snapshot dokumen luar selalunya baca kod lama (contoh: sessionGate fix 11 Okt, laporan masih kata open).
3. **Angka tanpa provenance = UNRECONCILED, bukan SALAH** (contoh: "61+ seals" — 4 baris dlm fail yang dicari ≠ bukti angka itu bohong; lima ontologi mungkin).
4. **Four-gate:** (1) claims vs live state, (2) Phase mismatch — Phase E infra untuk Phase A problem = PARK, (3) naming sovereignty, (4) doctrine contradictions.
5. **Keputusan Arif utk blueprint Phase-E: horizon map sahaja** — simpan resit, sifar kod, sifar organ baru.
6. **Prinsip import:** "ambil invariant, jangan import machinery."

## Hukum penutup (dipratik dua kali sesi 29 Okt)

> Sumber kod boleh membatalkan dakwaan lama, tapi hanya bukti atas wayar dan resit bebas yang boleh menutup luka.

Source-fix PRESENT ≠ closure. Wire negative test diperlukan. Komen "REMOVED" dlm kod = niat, bukan bukti runtime.

## Tangga kelas epistemik (888, 30 Okt — audit 3-pusingan APEX)

Dakwaan mesti diikat ke KELAS, bukan prosa bebas:
DECLARED (dokumen kata) → IMPLEMENTED (kod ada) → DEPLOYED (package hidup muat kod itu
— sahkan dengan probe sanctioned, contoh `probe_runtime_source.py`) → OBSERVED
(tingkah laku disaksi sekali) → RECONSTRUCTED ( reproduksi bebas) → ACCEPTED (manusia
terima). Yang tak sampai = UNKNOWN, sebut dengan nama kelasnya.

Scar 30 Okt: aku grep kod → kata "veto jalan atas wayar". Kod ada ≠ perilaku berlaku;
malah komen kod sendiri kata "measured Phase E, not this v1". Tarik balik sendiri
sebelum orang lain tarik — yang menarik balik kawal naratif, yang kena tangkap kawal resit.

Ladder menjatuhkan 3 kes malam ni: komen kod → DITARIK dari OBSERVED;
sanctioned probe → IMPLEMENTED dinaikkan ke DEPLOYED; live judgment tak dipanggil →
causal chain kekal UNKNOWN.

## Defect sendiri yang diakuu

Audit pertama label "defect ditutup" dari komen kod sahaja = self-certification, corak sama dengan laporan yang diaudit. Tarik balik sebelum orang lain tarik.
