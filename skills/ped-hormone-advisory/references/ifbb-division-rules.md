# IFBB Men's Physique & Classic Physique — weight caps

**Two federations, different rules. Establish which one before answering.**

- **IFBB Pro League** (NPC route → Mr. Olympia): Men's Physique **has** height-indexed maximum weights, introduced after the 2023 Mr. Olympia. Each cap is exactly **10 lb (4.5 kg) below the Classic Physique cap** at the same height. Every pro is heighted and weighed at every show, and over-cap means out.
- **IFBB international** (amateur / world championships): Men's Physique is **height classes only, no weight cap** — Class A ≤170 cm, B ≤173, C ≤176, D ≤179, E ≤182, F >182. Classic Physique carries the bodyweight formula.

## Classic Physique formula (IFBB rules)

Max weight [kg] = (height [cm] − 100) + offset. Offsets: up to & incl. 168 cm → +4; incl. 171 → +6; incl. 175 → +8; incl. 180 → +11; 180–188 → +13; 188–196 → +15; over 196 → +17. Some editions carry an extra +4…+9 kg tail on top — read the current PDF rather than reusing these numbers from memory.

## Where to check

- `ifbbpro.com/rules` — Pro League heights and weights, re-issued each season.
- `ifbb.com/wp-content/uploads/RULES/Mens-Physique-<year>.pdf` — international division rules: categories, rounds, judging criteria.

Re-check the current season's PDF before quoting. These tables are re-issued and the numbers have moved before.
