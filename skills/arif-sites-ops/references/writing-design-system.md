## Class inventory (canonical list — present in both inline + shared versions)

### Structure
- `.frame` — centered 720px reading column wrapper
- `.cover` — full-width hero block (centre-aligned, gold gradient top)
  - `.cover-emoji`, `.cover-kicker`, `.cover-title`, `.cover-subtitle`, `.cover-byline`
- `.nav` — top navigation (flex, mono, uppercase), `.nav a.here` = active state
- `.footer-note` — mono footer with top border

### Typography helpers
- `.meta` — mono uppercase label line
- `.author` — mono author byline
- `.lead` — large bold opening paragraph
- `.note` — bordered aside (used on index pages)

### Content blocks
- `.pull-quote` / `blockquote` — italic blockquote, gold 3px left border, gold-soft bg
- `.fact-box` — evidence box (elevated bg, gold left rule)
  - `.fact-box-title` — mono gold uppercase heading
  - `.fact-box-content` — body text
- `.callout` — action item box (gold-tinted gradient bg, gold border)
  - `.callout-title` — mono gold uppercase heading
- `.zen-pulse` — 3-question pulse bar (3-col grid)
  - `.zp-item` — individual Q/A card (gold left border)
  - `.zp-ask` — mono question label
  - `.zp-val` — display-serif answer

### Interactive / navigation
- `.chips` — filter chip list (pill-shaped, `.is-active` gold state)
  - `.chip` — individual chip
- `.card` — article card (border, rounded, hover highlight)
  - `.card.new` — featured/NEW card (gold border + gold-soft bg)
  - `.badge` — inline gold mono label (e.g. `NEW · 2026-08-07`)
- `.series-label` — mono uppercase section divider

### Layout
- `.compare` — 2-column comparison grid (collapses 1-col on mobile)
  - `.label` — mono gold heading
  - `.pay-up` — green left border (positive outcome)
  - `.pay-down` — red left border (negative outcome)
- `.chain` — vertical decision chain (left border, monospace steps)
  - `.arr` — gold arrow glyph
  - `.new` — highlighted (stronger) step

### References
- `.ref` — superscript reference link (gold, bold)
- `.ref-list` — numbered reference list (ol)
- `.epistemic` — inline badge (border, mono, uppercase)
  - `.tag` — gold keyword inside epistemic badge

## Responsive breakpoints

- 720px: frame padding shrinks, cover scales, zen-pulse stacks to 1-col
- 600px: body font 16px, headings smaller, compare stacks, nav tighter
- 380px: cover title / nav smallest
- print: nav + footer hidden, white bg, black text

## Decision tree — shared CSS vs inline

**Use shared CSS (`/_shared/writing.css`)** if you are:
- Hand-authoring a static page that bypasses `render-words-essays.cjs`
- Writing a long-form template in `templates/essay-standalone.html` for the user to copy-edit
- Building a tool that needs essay styling outside the build pipeline

**Use inline `<style>`** if you are:
- The generator itself
- Anything that will be regenerated by the generator

## Patch the generator (one-line, T1, reversible)

In `scripts/render-words-essays.cjs`, replace the inline `<style>...</style>` block in the essay template with:

```html
<link rel="stylesheet" href="/words/writing/_shared/writing.css" />
```

Then re-run `npm run build`. All essay pages will share the CSS. To revive the orphan file: re-emit it from the inline style block (extract from any of the generated essay pages) into `public/words/writing/_shared/writing.css` and `dist/words/writing/_shared/writing.css`, then rsync to live webroot.
