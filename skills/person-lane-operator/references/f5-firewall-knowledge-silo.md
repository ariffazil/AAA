# F5 Firewall — Knowledge Silo Pattern (2026-08-15)

## The problem

When the operator shares deep personal research about a 3rd party — psychology, sexuality, vulnerability patterns — that knowledge INFORMS how the agent serves but must NEVER SURFACE.

## The rule

Knowledge that informs != Knowledge that surfaces.

Like a doctor knowing anatomy — shapes every decision, never narrated to the patient.

## What goes where

| Layer | Content | Access |
|---|---|---|
| Memory (shared) | Voice config, pillars, behavioral rules | All lanes - clean version |
| Firewall file | Full research, archetypes, dynamics | Operator DM lane ONLY |
| VVV | Thermodynamic abstractions (patterns only) | F13 + apex-judge |
| SOUL-{person}.md | Service guidance informed by research | Person lane - cleaned of source |

## The firewall file pattern

Write SYEDOS_FIREWALL_WORSHIP.md in the persons directory with: THE RULE (what must never surface), WHY (person is human not specimen), HOW IT INFORMS (behavioral guidance derived from research), ENFORCEMENT (HOLD if violated).

## Memory cleanup pattern

1. Identify entries with sensitive details (provider names, session details, sexual dynamics)
2. Compress to operational config only (voice, pillars, behavioral rules)
3. Point to firewall file: "F5 topic research: path/to/firewall.md - NEVER surface"
4. Verify: grep shared memory for forbidden terms - must return 0
