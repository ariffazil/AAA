# HERMES Meaning-Integrity — the 13-family routing index

**One-line law:** HERMES normalizes, classifies, routes, receipts — it NEVER judges
(five-verb contract, `/root/.hermes/AGENTS.md`). Verdicts → arifOS `arif_judge` ·
Mutations → A-FORGE · Readiness → WELL · Consequence math → WEALTH · Temporal truth → CHRON.

discover HERMES capabilities by skill lookup (audit 2026-10-06,
`/root/AAA/reports/skills-alignment-2026-10-06.md`). This index is the connector.
