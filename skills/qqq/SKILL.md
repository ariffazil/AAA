# /qqq

Follow `/root/AAA/governance/QQQ_RECOMMENDATION_PROTOCOL.md`.

- **Q1 Qualitative:** enumerate the full option space, including do-nothing and the smallest reversible step.
- **Q2 Quantitative:** for each path, state cost, risk, time, reversibility, blast radius, and evidence class.
- **Q3 Quantum:** second-order effects, failure modes, who pays, and what changes if the path is wrong.

Missing any layer = `INADMISSIBLE-QQQ-INCOMPLETE`. Do not present a verdict or a menu without all three.
