# Transaction Void Sweep & Valuation Banding

Depth for steps 6 and 9 of `deal-consolidation-intelligence`. Load when a deal is rumoured but not announced, or when price is the disputed variable.

## 1. The transaction-mechanics void sweep

For a *published disclosure*, the void layer sweeps corporate narrative vocabulary. For a *rumoured* transaction there is no disclosure to sweep — so sweep the record for the vocabulary that any real transaction is forced to emit, and check every category against the last ~24 months of filings, regulator pages, rating-agency releases and credible press.

| Category | Terms a live deal cannot avoid emitting | If absent |
|---|---|---|
| **Regulatory process** | approval to commence negotiations; extension application; waiver; condition variation; regulator statement | No live negotiation is in documentation |
| **Transaction mechanics** | adviser mandate / RFP; valuation; share-swap ratio; due diligence stage; binding agreement language; long-stop date | Nothing is being modelled, let alone signed |
| **Capital structure** | rights issue; capital injection; sukuk or bond framed for a purchase; new equity; group guarantee | The funding for a purchase does not exist yet — and this appears *years before* an announcement |
| **Numbers a deal requires** | synergy target; integration cost; post-merger cost-to-income; goodwill estimate; branch-overlap or headcount count | No integration work has begun |
| **People** | succession tied to a transaction; board renewal framed around it; retention arrangements | Leadership is not being prepared for a change of control |
| **Forward structure** | listing venue; IPO timetable; dividend policy for a combined entity; target return metric | The end-state is undefined even privately |
| **Political economy** | state-federal framing; mandate language; equity-policy argument; ministerial statement | The transaction has no political sponsor, which deals of this class normally require |

**Reading the result**

- **Uniform absence across every category** = there is no live transaction. Output: the pressure is real, the event is not. Date-stamp the verdict.
- **One or two categories present, rest absent** = a specific *pressure point* (an unmet condition, a licence deadline, a shareholder exit wish) with no process behind it. Name the pressure, name the absence, and give the reader the tripwire.
- **Clustered presence** (regulatory process + mechanics + capital) = a live deal. The brief changes shape entirely: probabilities, timeline, and the step-by-step disclosure sequence it will follow.

**Predictive use.** Publish the expected disclosure *sequence* for a real deal — approval to negotiate → adviser mandates → extension application if it drags → capital structure → material-terms announcement. Watching for step one is sufficient; everything else is commentary. A monitoring list built on this is a deliverable in its own right.

## 2. Valuation banding

Use when price is disputed and no transaction has been struck. Never publish a point estimate here — it is false precision on a number no participant has accepted.

**Anchor set** — build each edge from a real precedent:

| Anchor | What it is | Why it matters |
|---|---|---|
| **Owner's own entry price** | the multiple the current controller itself paid for the stake | the strongest seller anchor: it functions as the reference the seller will not go below |
| **Last comparable acquisition** | the clearing multiple of the most recent similar transaction in the sector | the strongest buyer anchor: it is what a board can defend to its own shareholders |
| **Prevailing sector trading multiple** | the range at which listed peers trade on book | bounds the range from the market's side and kills unrealistic asks |

**Construction:** target book value × each multiple ÷ shareholding split, giving implied value per shareholder. Present as a table with each row naming its precedent.

**The asymmetry that explains the deadlock.** A seller anchors to its own entry price and to the top of the band; a buyer anchors to the last clearing price and the bottom. Where the two anchors are years apart and nothing has moved between them, that gap *is* the explanation for the absence of a deal — state it as the finding rather than listing "valuation" as a generic risk. This is the analytic payload of the band: not the number, but the width of the disagreement and its persistence.

**Sanity checks:** compare the implied stake value against the parent's own market capitalisation (a stake worth more than the whole listed parent is a structural reason the sale stalls); compare the target's contribution to group profit (a target carrying a large share of group earnings damages the parent on deconsolidation, which is a second independent reason to hold).

## 3. Companion-brief inversion

When a follow-up brief reframes the objective ("assume the goal were X — what would it take?"), re-read every finding from the first brief *under the new objective* before writing anything new. Findings invert more often than they carry over cleanly.

Worked shape: brief one establishes a deadlock and reads it as institutional failure. Brief two takes a long-horizon transformation as the objective — and the same deadlock becomes the *precondition*, because the only ownership form that can absorb a decade of below-market returns is one that has already demonstrated it will hold an underperforming asset rather than sell at a price it dislikes. The finding is only visible because brief one exists.

Discipline: name the first document as the companion, keep the numbers consistent between them, and flag the inversion explicitly rather than quietly reversing a conclusion. A reader holding both documents needs to be told which earlier judgement has changed and why.
