# Audit output template

Reproduce this skeleton. Keep every section, including the ones the evidence makes thin — a thin
section is a finding; a missing one is a hole.

```
0. EVIDENCE BASE
   table: corpus | span | volume | active days | sender split | SOURCE CLASS
   one paragraph naming the contamination class being held constant

1. EXECUTIVE COMPRESSION  (<=10 lines, no archetype labels unless directly earned)

2. CHRONOLOGY  (date | event | layer: OBSERVED / REPORTED / INFERENCE / UNKNOWN)

3. BEHAVIOURAL INVENTORY
   A -> B   (observed behaviour only, first)
   B -> A   (observed behaviour only, first)
   interpretation after both lists, never interleaved

4. RECIPROCITY LOOP
   the loop drawn from events, not from the hypothesis
   instances (N) | strongest evidence | exceptions | confidence
   N=1 episode - N=2 possible recurrence - "pattern" only on genuine repetition

5. ATTENTION / ADMIRATION MECHANICS
   one row per rung, each with its own confidence:
   generic attention - specific attention (each direction) - selective attention -
   expected attention - provoked attention - possessiveness - dependence

6. POWER MATRIX  (domain | A | B | evidence | confidence)

7. HYPOTHESIS TESTS
   per hypothesis: verdict - best evidence - counterevidence - alternative explanation - 0.00-1.00

8. WHERE THE REQUESTER'S MODEL EXCEEDS THE EVIDENCE
   the exact gap named, without calling it projection

9. WHERE THE AI PROJECTED  (table: transformation | where | correction)
   include this session's own errors

10. NEGATIVE EVIDENCE  +  where the absence is weak because the archive is incomplete

11. THREE OBJECTS  (A actual / B model / C persona) with the overlap stated

12. UNKNOWN REGISTER  (every unresolved variable; each is a successful result)

13. MINIMUM TRUE MODEL
    "The archive establishes X, Y, Z. It suggests A with confidence N because M.
     It does not establish C, D, E."  Then stop.
```

## Register and storage

- An audit about a real, named human is private-lane material: write it to the private lane directory,
  `chmod 600`, append-only (add dated sections, never overwrite).
- It does NOT go to canon, to the shared federation memory, or into a persona/creative archive. Grep
  those trees after writing to confirm the firewall held.
- If the audit's subject also has a creative/persona lane, add a one-line pointer in THAT skill saying
  the craft artifacts are never evidence about the person — the firewall has to be readable from both
  sides or the next session will cross it.

## Closing discipline

End on the minimum model and the UNKNOWN list. Do not add a hopeful coda, do not resolve tension the
record did not resolve, do not offer what to do about it unless asked. The audit's job is to leave the
requester with a smaller, truer object than the story he arrived with.
