# Parliamentary Email Research Pattern

## When to use
- User asks "siapa patut kita email" or "list MPs" or "find emails for parliamentarians"
- User wants to send open letters / formal correspondence to Malaysian MPs
- Research on Malaysian political figures for advocacy purposes

## Source: parlimen.gov.my

### Finding MP profiles
```
https://www.parlimen.gov.my/profile-ahli.html?uweb=dr&id=<NUMBER>
```
Each MP has a profile page with: name, party, constituency, phone, fax, email, address.

### Key patterns
- Email format: usually `<name>@parlimen.my` or personal Gmail (e.g. `syedsaddiq92@gmail.com`)
- Ministers have `.gov.my` emails (e.g. `menteri@digital.gov.my`, `liewchintong@mof.gov.my`)
- PAC email: `pacparlimen@parlimen.my` (Jawatankuasa Kira-Kira Wang Negara)
- Not all MPs have public emails on parlimen.gov.my — some profiles show phone only

### PAC members (2026)

## Workflow for compiling MP email list
1. Start with PAC members (most relevant for Petronas oversight)
2. Add constituency-specific MPs (Johor for Petronas operations, Sarawak for Petronas-Petros)
3. Add vocal/opposition MPs who would push the issue
4. Add key ministers as CC targets
5. Add media/podcast hosts (KJ, Shahril) for amplification
6. Compile into CSV for easy email client import
7. Total target: 33+ emails for a serious one-shot campaign
