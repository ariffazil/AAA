# Research-Frontier Page Template (5-part)

> Copy-paste template for any Register B page. The structure was forged by Arif (2026-08-11) as the keystone pattern. If you can't fit your topic into these 5 parts, your topic either belongs in A (it's already mature) or C (it's an internal vulnerability). Restructure before publishing.

## The template

```markdown
# <Topic name — paradox-visible in title>

> **Register B — Research Frontier**
> **Status:** Proposed / Under audit / Ratified / Closed
> **Last updated:** YYYY-MM-DD
> **Audience:** Researchers, potential collaborators, public
> **Related:** Register A pages on stable doctrine · Register C receipts (link if appropriate)

---

## 1. Question

One sentence. State the paradox or gap as a research question.

> How can [subject] achieve [goal] without [violation]?

Concrete examples (Arif, 2026-08-11):
- "How can constitutional systems learn without self-authorizing constitutional mutations?"
- "How does a federation calibrate confidence bands by claim class?"
- "How can an agent detect when a metric is being Goodharted?"

---

## 2. Evidence of Gap

Concrete reference to missing code, doc, or primitive. Be specific — give file paths, line counts, doctrine references.

> /path/to/repo/ contains X stable since YYYY-MM.
> Specific primitive Z is missing — would need [description].
> Adjacent doctrine covers A but does not generalize to B because [reason].

Example for E22:
```
/root/arifOS/GENESIS/ contains F1-F13 floors stable since 2026-07.
Floor changes require F13 sovereign consent (F11/F13 binding).
No machine doctrine exists for non-sovereign-initiated evolution.
Truth metabolism (E20) re-verifies truth claims, not constitutional claims.
Scar-to-Law pipeline handles scars, doesn't generalize to constitutional drift.
```

---

## 3. Would-Become-True Criterion

Testable closure condition. Future agents must be able to falsify this — that's the point.

> Gap closes when a proposed [thing]:
> - originates from [observed condition]
> - passes [audit gate]
> - is ratified by [authority]
> - leaves [audit trail]
> - does not enable [forbidden outcome]

Example for E22:
```
Gap closes when a proposed amendment:
- originates from observed contradiction (reality-driven, not human-driven)
- passes 888 triple-pass audit
- is ratified by F13 (sovereign remains the gate)
- leaves auditable trail (F11 preserved)
- does not enable self-modifying law
```

**Falsifiability rule:** if a researcher can't write a fix and check it against this criterion, the page is performative, not auditable. Restructure or remove.

---

## 4. Why It Matters

1-2 sentences. Stakes, not philosophy.

> Without this, [concrete failure mode]. [Specific system-level consequence].

Example for E22:
```
Without this, constitutions become museums.
F13 is a single point of failure across the entire federation.
```

---

## 5. Current Status

Date + latest action + next concrete step. Brief. No philosophy.

```
YYYY-MM-DD: <what just happened>
YYYY-MM-DD: <next concrete action>
Blocked on: <specific dependency, if any>
Ratification path: <F13 / 888 / arifOS kernel / etc.>
```

Example for E22:
```
2026-08-11: Proposed as keystone by Arif, awaiting F13 ratification.
Next: forge the amendment-proposal primitive in arifOS kernel.
Blocked on: F13 sovereign consent to ratify the research program itself.
```

---

## What NOT to include

- Implementation details (which file, which line) — that's Register C
- Specific vulnerabilities or error rates — that's Register C
- "Future plans" beyond the next concrete step
- Marketing-grade framing of the gap
- Solution proposals — only the QUESTION and CRITERION go public. Solutions stay in C until ratified.
```
