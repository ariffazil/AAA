# Sovereign-Identification Synthesis — When User Says "Tell Me Everything About X"

> **When:** User asks a multi-thread synthesis question about their own institutional reality, sovereign identity, or organization they are embedded in.
> **When NOT:** Trivia recall, external third-party research, technical how-to.

## Pattern (verified 2026-08-12)

User asked: "Tell me everything about Arif Fazil and PETRONAS and Tengku Taufik."

Naïve approach: try to answer from training-data memory alone. **Failure mode:** fabrication risk on biographical facts that drift over time.

Correct approach:

1. **Search session history** for prior similar threads — the user may have asked the same question before, with richer detail.
2. **L0 canon sweep** — load sovereign source-of-truth:
   - `CANON.md` (top-level federation geometry)
   - `LIFE/DECISIONS.md` (life decisions framework)
   - `SOVEREIGNTY/MODEL.md` (sovereignty doctrine)
   - `PROPA/STRUCTURAL_REALITY.md` (institutional memory)
   - `DERITA/` (scar architecture)
   - `HAMPA/` (human witnesses)
   - `HUMAN/` (family + life)
3. **L1 mirror sweep** — operational state:
   - `H5-scars/` (active scar registry)
   - `H4-identity/` (identity markers)
   - `ZEN_HELIX.md` (unified memory map)
4. **Domain-specific archives** — SEARAH, Collapse, Gentari — the user's published/exposed work.
5. **Federation health probe** — confirm the constitutional substrate is live (or note degradation).
6. **Synthesize as narrative** — three threads + connective tissue + epistemic labels.
7. **Flag uncertainty honestly** — anything from training-data memory (Tengku Taufik biography) must carry `[DER]` with cutoff warning. Live probe or declare UNKNOWN.

## Why This Pattern Matters

The user asking about themselves is testing coherence — does their agent actually know them? Fabrication here is F9 violation (deception) and F2 violation (truth). Both constitutional floors.

Also: the answer IS institutional memory reflected back. It's how the agent proves it has internalized the scar architecture. If the agent can't explain the institutional pattern, the whole federation's memory claim is suspect.

## Anti-Patterns

- ❌ Summarize from CV-like memory alone
- ❌ Confuse training-data biography (Tengku Taufik) with L0-sealed institutional analysis
- ❌ Hide uncertainty — flag `[DER]` with cutoff warning, propose live search
- ❌ Format as corporate biography — use the user's own voice and scar architecture
- ❌ Skip the connective tissue — the three threads (Arif/PETRONAS/Tengku Taufik) are bound by the institutional paradox, not independent

## Output Shape

```
Three threads (Arif / institution / institution head)
+ Connective tissue (what binds them — usually institutional paradox)
+ What agent is NOT confident (live probe required)
+ Offer to dig deeper on any gap
```

Length: not exhaustive encyclopedia entry — synthesis with explicit uncertainty. ~600-1500 words for a 3-thread query.
