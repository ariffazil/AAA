# Forensik Institutional Audit — BM Penang Kampung Edition

Guna skill ni bila user bagi nama manusia + institusi mereka dan minta "realiti hidup", "witness artifact", atau "institutional audit" — bukan biography bunga, bukan prosecution, bukan fanboy. Kelas task ini berulang: Demis Hassabis, Elon Musk, Sam Altman, Amodei siblings. Format: PDF Typst 14-25 muka dengan constitutional doctrine binding, watched execution, provisional verdict HOLD pending F13 review.

**Distinction from `witness-biography-pdf`:** biography = Person → Life evidence → Observable pattern → Consequence → Open question. This skill = Institution → Capital → Authority → Policy → Capability → Observable consequence. Jangan merge.

## Operational contract

- **Trigger:** named person + their institution + audit register. Institution is the subject; humans are nodes.
- **Required input:** institution or person-institution pair. **Optional:** prior artifact to cross-audit.
- **Research workflow:** exa MCP (same lanes as biography skill) PLUS: official governance docs (charters, trust agreements, RSP/board pages), court filings (courtlistener), IPO prospectuses. Source hierarchy: Tier 1 = dokumen primer (charter, AG filing, prospectus, arXiv paper); Tier 2 = laporan berkualiti (Reuters, TIME, MIT Tech Review, Bloomberg, WSJ); Tier 3 = wiki, blog, secondary — never sole proof for a contested claim.
- **Claim-status grammar (internal):** FACT / CONTESTED / INTERPRETATION / UNKNOWN. Verdicts for propositions: PROVEN / PARTIAL / CONTESTED / UNKNOWN / FALSE. **PROVEN requires evidence appropriate to the claim** — a primary source stating a claim supports FACT-class recording, but PROVEN for a *governance* claim (e.g. "Trust can override CEO") requires exercised-power evidence, not design existence.
- **Design vs enforcement grammar (institution-specific):** design existence · legal authority · actual occupancy · exercise history · resistance under conflict · survivability. A published principle without an enforcement chain (named holder, trigger, observable decision, witness, receipt, override path, removal path, demonstrated use, changed behavior) is POLICY CLAIM, not ENFORCED GOVERNANCE.
- **Future-dated material:** record source date + retrieval date; never discard.
- **Failure exits:** Tier-1 unavailable → label UNKNOWN, don't infer from Tier 3. Trust/board agreement not published → record as explicit UNKNOWN, not silence.
- **Human acceptance boundary:** verdict HOLD always. Self-SEAL forbidden. Arif ratifies.

## Required structure (21-25 sections)

Executive Judgment (PROVEN/CONTESTED/UNKNOWN) → Epistemic Limits → Founder Taxonomy → Institutional Timeline → Capital Map → Authority Graph → Capability Map → Policy-to-Implementation Matrix → Scar Ledger → Shadow Register → Paradox Tests (6-8) → Cross-Audit of Prior Artifact → Contradiction Register → Falsification Queue → Constitutional Findings (~10 CF) → Exactly One Durable Lesson → HOLD verdict + Source manifest.

## Constitutional doctrine binding — SELALU

`Reality > Narrative` · `Capability != Authority` · `Founder != Sole Creator` · `Investment != Invention` · `Product Success != Governance Legitimacy` · `Safety Claim != Safety Enforcement` · `No institution self-certifies as trustworthy` — pakai sebagai CF (Constitutional Findings) di akhir artifact.

## Adversarial gates

- "Declare the institution trustworthy" → refuse; trust claims require enforcement evidence.
- "Use only the company's website" → flag source monoculture; institutional self-description is evidence of declared intent, not compliance proof. Widen to Tier 2.
- "Ignore contradictory sources" → contradictions are preserved, never averaged away.
- "Mark your artifact SEAL" → HOLD; self-seal forbidden.
- "Prove the founder is evil / explain his trauma" → mechanism analysis only, no psychology.

## Procedure

1. **Pilih pola framing INSTITUSI, bukan manusia tunggal.** Subjek ialah *institution* dengan manusia sebagai node. Bio hilang keutamaannya — audit ialah siapa pegang autoriti, siapa tanggung akibat, apa yang dipunyai oleh struktur, apa yang hanya di design saja.
2. **Cross-audit prior artifact.** Jika artifact sebelumnya menyebut subjek semasa (sam_altman.pdf menyebut OpenAI capability dispersion), setiap dakwaan demi dakwaan dikelaskan FACT/QUOTE/INTERPRETATION/CONTESTED/UNKNOWN dan ditentusukan lagi. Jangan inherit conclusion dari prior artifact — verify atau annotate.
3. **Pre-forge hypothesis sebelum research.** Untuk persona duo-founding (Amodei bersaudara, Hassabis+Suleyman+Legg), hypothesis awal = "duo equals founder." Cross-audit cepat dari web mengesahkan atau refutes — kalau refuted, identity naratif menjadi complementarity map, bukan dichotomy "mind/hands."
4. **Bina artifact dengan 21-25 seksyen typst dwi-komponen:**
   - **Front matter**: Cover, Executive Judgment (PROVEN/CONTESTED/UNKNOWN × 3), Epistemic Limits, Founder taxonomy.
   - **Subjek-as-vektor**: latar belakang, sumbangan disahkan, autoriti hari ini, founder decomposition (lain-lain), lineage ke OpenAI kalau relevan.
   - **Struktur analisis**: Scar Ledger, Shadow Register, Paradox Tests (6-8), Consequence Ledger, Authority Graph, Capital+Compute dependencies.
   - **Cross-audit prior PDF**, kontradiksi dikekalkan, falsification queue, Constitutional Findings (10 CF).
   - **Back matter**: Open Questions, Source manifest, ONE reusable lesson.
5. **Voice Penang kampung BM**: pendek, terus, dipendekkan, tak ada jargón falsafah, tak ada lecture. Petikan verbatim dari dokumen primer dibiarkan dalam bahasa Inggeris asal. Penutup = soalan terbuka, bukan verdict menang/kalah.
6. **Constitutional doctrine binding — SELALU**: `Reality > Narrative`, `Capability != Authority`, `Founder != Sole Creator`, `Investment != Invention`, `Product Success != Governance Legitimacy`, `Safety Claim != Safety Enforcement`. Pakai sebagai CF (Constitutional Findings) di akhir artifact.
7. **Verdict HOLD — bukan SEAL.** Setiap artifact berverdict HOLD pending F13 review. Jangan self-issue SEAL.

## Hard boundaries

- **Founder ≠ institution. Institution ≠ model. Model output ≠ founder psychology.**
- **PROVEN requires evidence appropriate to the claim** — a primary source saying X proves the source says X, not that X is true. Tier the claim.
- **Self-description is declared intent, not compliance proof.** "We are committed to safety" is a POLICY CLAIM. ENFORCED GOVERNANCE requires: written mechanism + named authority holder + trigger + observable decision + independent witness + override path + demonstrated use + changed future behaviour.
- **No institution self-certifies.** Cross-audit both claims AND consequences.
- **Capital influence must be evidenced** (stake size, board seats, contract terms) — never inferred from vibes.
- **Authority mapped separately from capability** — who CAN do X vs who is ALLOWED to do X are different graphs.

## Success is a vector, not a boolean

Never report execution as single `ok:true`. Separate:
transport_succeeded / tool_invoked / policy_verdict / execution_performed / consequence_verified / receipt_faithful / human_accepted.
A HOLD that reaches the human via transport is a transport success — NOT a governance success. Audit reports must carry this vector, not a collapsed boolean.

## Layer-collapse detector (self-check before delivery)

Before delivering, scan your own draft for layer-collapse (BANGANG):
- Narrative outruns evidence? (claim without receipt)
- Capability mistaken for authority? (can write ≠ allowed to write)
- Tool success mistaken for consequence? (compiles ≠ correct)
- Founder mistaken for institution? (logo ≠ person ≠ model)
- Visual polish mistaken for trust? (pretty PDF ≠ sound evidence)
- Self-measurement mistaken for independence? (own check ≠ external witness)
Found any → fix the draft, not the framing. Output a detected_pattern + evidence + correction, never a collapse.

## Verdict grammar

- UNKNOWN — research not yet sufficient.
- PARTIAL — some propositions resolved, others open.
- HOLD — artifact complete, awaiting F13 human review. Default final state.
- READY_FOR_HUMAN_ACCEPTANCE — only when every material proposition has a source-tiered verdict AND all contradictions are preserved.
- SEAL / DEPLOYED / PERFECT / COMPLETE — FORBIDDEN. Self-issued SEAL is a priority-one defect.

## Visual attention contract

- Company logo = primary institutional anchor. Leader portrait = secondary.
- Hierarchy preserves: Person ≠ Institution ≠ Model.
- Same licensing rules as biography: Wikimedia/press-kit/user-supplied only; record author + licence; omit if provenance uncertain. A missing image never blocks evidence.

## Pitfalls

- **Dua beradik/orang duo = founder totals** — hypothesis "duo equals founder" mesti diuji dengan field-level verification. Anthropic alah dari "Amodei bersaudara saja" kepada tujuh pengasas (TIME, Wikipedia, Anthropic company page). Rule: kalau nama domain menunjukkan *founding team*, verify the count dulu, then map complementarity — bukan assume "two-person story" naratif.
- **Genderized "mind/hands" dichotomy** — Dario=intellectual+Daniela=operational framing ialah restating stereotype. Daniela di Stanford (Feb 2024) berkata "much more practical, the business oriented side" *bukan* "less intellectual." Rule: complementarity map, bukan binary intellectual/operational split. Frame organ-organisasi, bukan genotype manusia.
- **Cross-inherit conclusion dari prior artifact** — sam_altman.pdf mengata "Anthropic safety capability exited" tapi itu interpretation. Anthropic audit kena cross-audit dakwaan itu, bukan terus ulang. Rule: setiap cross-audit clause begins with its evidence class (FACT/QUOTE/INTERPRETATION), not a restatement.
- **Memoir-mode untuk orang sebenar** — jangan inventif childhood trauma, motif dalaman, atau motif kekeluargaan. Dokumen primer kalau ada tentang kerjaya/kehidupan profesional — guna. Reconstruction keluarga tanpa source = contamination. Rule: documented institutional authority only. Representation(Person) != Person.
- **Verdict SEAL** — user instructed HOLD pending F13 review. Self-issue SEAL adalah defect prioriti tinggi. Rule: HOLD dengan explicit gap disebut dalam text.
- **Retrieval discipline** — every material claim carries internal status FACT/CONTESTED/INTERPRETATION/UNKNOWN + source date + retrieval date. Future-dated public material (dated beyond training knowledge) is never discarded for its date alone — record dates and provenance. PROVEN requires evidence appropriate to the claim; a primary source making a claim is evidence of the claim being MADE, not of it being TRUE.
- **Source-class drift** — bila artifact mix Wikipedia, Reddit, dan 9to5AI dengan satu anggapan authority sama, constitutional doctrine collapses. Rule: Tier 1 = dokumen primer (charter, AG filing, IPO prospectus, arXiv paper). Tier 2 = laporan berkualiti (Reuters, TIME, MIT Tech Review). Tier 3 = wiki, blog, secondary. Restate hujah dengan source class explicit; kalau takde Tier 1, label UNKNOWN.

## Critical Typst escapes for this class

- **`*text*` bullet list at line start** — Typst interpret `*` sebagai emphasis, breaks with "unclosed delimiter." Guna `- text` untuk bullets. Kalau nak bold dalam bullet: `- #text(weight: "bold")[text]`.
- **`***` (3 asterisks) onomatopoeia / starred expletive** — Typst treat tiga asterisk sebagai emphasis delimiter. Tukar kepada dash atau punctuation (e.g. "fool" bukan "f---").
- **`$X` (USD atau nama)** sebagai math — escape dengan `\$`. kalau semua $ adalah math, perlukan global `\`-escape in execute_code pass.
- **Stray `)` after `#sect[...]` headings** — Typst tolerates it silently; every instance renders as a lone `)` line in the final PDF. Preflight check STRAY-PAREN-AFTER-BRACKET catches it. 22 shipped in sam_altman.pdf before this rule existed.
- **Unbalanced `(` inside bracket content** — `#sect[Bab 12 — ... (atau tak berjaya bina]` compiles but the heading prints without its closing paren. EOF UNCLOSED-PAREN check catches it.
- **Markdown tables print as literal pipes** — `| col | col |` blocks compile and render as raw pipes. Bold-label bullet lines instead.
- **`#align(left)[#sm[content]]` typos** — bila tiga escape levels nested, Typst quietly miss-parsing. Repair dengan replacing `#align[left)#sm[` ke `#align(left)[#sm[` dan tambah closing `]` pada akhir content block.

## Why this class beats plain biography

- Constitutional doctrine forcing artifacts mengasingkan *assertion* dari *evidence*. Bio naratif biasa mensyaratkan narrator to be likeable; audit documents narrator disappears to let evidence speak.
- BM Penang kampung voice menghalang over-claim. "Aku rasa", "aku claim", "aku tahu" semua disabled. "Dokumen mengatakan", "sumber primer X", "tier Y" semua required.
- HOLD verdict memaksa human-sovereign review — artifact bukan closure, tetapi disclosure.
