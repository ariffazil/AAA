## The Core Principle

**Dispatch is NOT a single event. It is an 11-tier sequence ordered by blast radius, witness function, and constitutional protection.**

Each tier serves a DIFFERENT function:
- Some amplify (media, opposition voices)
- Some witness (NAIO, regulators)
- Some notify (defendant BoD)
- Some ally (aggrieved parties like PETROS)
- Some record (PMX, Speaker)

Conflating these functions creates uncontrolled blast radius and unnecessary exposure.

## Why Defendant Goes in SAME Envelope as Primary

**Iron rule:** PETRONAS BoD receives the letter in the SAME dispatch as PAC, NOT separately.

Reasons:
1. **Formal right to respond.** They have standing to respond. Same-day notification respects that right.
2. **Paper trail integrity.** Sending separately creates asymmetric notification record (PAC receives Day 1, PETRONAS Day 3). Same envelope eliminates this asymmetry.
3. **Prevents coordination response.** If PETRONAS receives later, they have time to coordinate a unified response before public sees the letter. Same-day notification forces them to respond publicly to PAC and sovereign simultaneously.
4. **Documentary record.** Letter becomes public record at PAC. PETRONAS cannot claim ignorance.

**Implementation:** Same email blast (or postal batch), same timestamp, same CC list.

## Why Media Goes LAST (Day 4-5)

**Iron rule:** Never send letter to media before Parliament receives it.

Reasons:
1. **F9 ANTIHANTU trigger.** Letter to media first looks like performance, not petition. F2 TRUTH violation.
2. **Parliamentary privilege.** Once letter is at PAC, parliamentary correspondence is protected under parliamentary privilege. Media publication AFTER parliamentary submission is consistent.
3. **Strategic timing.** Day 4-5 allows PAC time to acknowledge receipt (which becomes news hook). If PAC stays silent, media publication becomes the trigger.
4. **Controlled leak vs open broadcast.** Media is not a primary recipient. Media is a controlled leak channel after primary petition.

**Anti-pattern:** Sending letter to media BEFORE PAC. This is the most common error in civic letter campaigns.

## Why Aggrieved Ally Goes in SEPARATE Letter

**Iron rule:** PETROS gets a SEPARATE letter (different envelope, different tone), not bundled in primary envelope.

Reasons:
1. **Different constitutional floor.** Primary letter is F1 AMANAH (to public authority). Ally letter is F6 EMPATHY (to aggrieved party).
2. **Different voice doctrine.** Primary is rupture voice. Ally letter is coalition voice.
3. **Different strategic function.** Primary is petition. Ally letter is invitation to joint action.
4. **Different protection.** PETROS may want to add their own signature. Bundling prevents that.

**Anti-pattern:** Bundling ally letter with primary letter. Forces ally into subordinate position.

## Sequencing Within Each Day

When sending to multiple recipients on Day 1, sequence matters:

```
DAY 1 TIMING:
08:00 MYT — Email batch to Tiers 1, 2, 3, 4, 6 (same envelope, single blast)
09:00 MYT — Postal registered mail to Pengerusi PAC (formal record)
14:00 MYT — Separate letter to Tier 5 (PETROS aggrieved ally)
17:00 MYT — Confirmation that all Day 1 dispatches landed (read receipts, postal tracking)
```

This sequence ensures:
- Same-day notification to all primary targets
- Formal record to Pengerusi PAC (registered mail creates additional documentary proof)
- Ally letter separate but same-day
- Confirmation loop before Day 2 escalation

## Anti-Patterns

### AP1: Single blast to all 82 contacts
Treats all recipients as interchangeable. Loses tier-specific voice and constitutional protection.

### AP2: Media first to maximize reach
Triggers F9 ANTIHANTU. Looks like performance. Damages parliamentary privilege.

### AP3: Defendant separately
Asymmetric notification creates paper trail weakness. Same envelope required.

### AP4: NAIO as CC, not prior witness
CC means NAIO receives with everyone else. Prior witness means NAIO receives Day 0 BEFORE anyone else.

### AP5: Ally letter bundled with primary
Forces ally into subordinate position. Separate letter preserves ally autonomy.

### AP6: Opposition voices asked to support
Sovereign becomes petitioner to opposition. Sovereign should be the petitioner to Parliament. Opposition chooses independently.
