## The Core Principle

**Letters to high-stakes public authorities evolve through 5-7 SUBSTANTIVE iterations before dispatch.** Each iteration crystallizes ONE structural lesson. The breakthrough is rarely the polished version — it's the rupture iteration.

The trajectory is NOT a serial polishing process. It is a parallel discovery process where each iteration tries a different cognitive move and the SOVEREIGN decides which move survives.

## Operating Principles for New Trajectories

### Principle 1: Each iteration crystallizes ONE structural lesson
Don't try to fix everything at once. If an iteration tries to fix voice + structure + asks + signature + distribution all at once, it will fail at all of them.

### Principle 2: The breakthrough is the rupture, not the polish
Most agents polish. Few rupture. v11 worked because it BROKE the previous pattern (named identity, direct address to institutions). Watch for the iteration that BREAKS — that's the watershed.

### Principle 3: 5-7 substantive iterations max
After that, convergence trap. If v[N+1] ≈ v[N], STOP. Use `multi-lens-parallel-forge`.

### Principle 4: Lessons are EVIDENCE in subsequent iterations
When v11 references "v9's 4 PARADOX blocks worked," that's evidence preservation, not repetition. Carry the scar forward.

### Principle 5: Document each iteration's lesson explicitly
Write a `letter-evolution.md` ledger as you iterate:

```markdown

- Crystallized: 4 PARADOX blocks + 4 audit asks format
- Discarded: anonymous positioning
- Carry forward: PARADOX block format
- Reason: structural format survived but voice too polite

## v11 — NUCLEAR Rupture
- Crystallized: named identity + named individuals + "berhenti sabar" rejection
- Discarded: over-length
- Carry forward: opening rupture + direct address
- Reason: voice breakthrough, needs structural wrapping
```

Don't lose the scar of what each version taught.

## Convergence Trap Detection

If the last 2 iterations are structurally similar:
- Same opening (or near-same)
- Same PARADOX structure
- Same asks
- No new named individuals or ruptures

...the trajectory has converged. STOP iterating. Use `multi-lens-parallel-forge` to dispatch 3 parallel agents with different cognitive lenses.

The lenses (per multi-lens pattern):
- **Lens 1 — Sovereign rigor:** Strict F2/F11 verification, conservative voice, all scars integrated as named proof
- **Lens 2 — Mak reconciliation:** One paragraph of tenderness toward real WhatsApp mak, then re-ratify rupture
- **Lens 3 — Compressed:** 6-8 pages max, surgical, less mak material, more institutional critique density

Each lens surfaces different structural improvements the polish iterations missed.

## Anti-Patterns in Iteration Trajectory

| Anti-pattern | Why it fails | What to do instead |
|--------------|--------------|-------------------|
| Polishing instead of breaking | Convergence trap | Force one structural rupture per iteration |
| Same mak voice across iterations | Repetition kills resonance | Rotate voice: mak → geologist → institutional → rupture |
| Factual errors uncaught (v3 lesson) | F2 TRUTH violation | External audit at every substantive iteration |
| Anonymous then named switch in middle | Identity discontinuity | Anonymous iterations first; named iteration ONLY at dispatch |
| Apologizing for the rupture (v11+ polish) | Defeats the purpose | The rupture IS the point. Don't soften it. |
| Skipping the convergence trap detection | Burn 5+ iterations on polish | After 5-7 iterations, force new cognitive lens |
