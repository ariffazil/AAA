### P16: Qualia vs institutional pretense (the hidden axis of sovereign letters)
Sovereign letters exist on TWO axes that often pull in opposite directions:

**F13 directive signal:** When sovereign says "Aku nak ditulis dengan penuh rasa qualia manusia" — they want Axis 2 dominant. When they say "Tenang, audit-focused" — Axis 1 dominant. Probe via "Now what do u really want?" if ambiguous.

The probe surfaces whether defensive language still serves.

### Multimedia Production Gotchas (verified 2026-08-12)

- **matplotlib `letter_spacing` is NOT a valid Text property** — causes AttributeError. Skip it; use plain text without character-spacing CSS analog.
- **`mpatches.Wedge((x,y), r, 0, 360, width=0)` renders HOLLOW** — for solid concentric core, use `mpatches.Circle((x,y), r, ...)`. (Already in pdf-report-generation skill.)
- **Edge-tts input length cap** — full 22K char surat times out. For TTS, use first 6000 chars (cover + opening + mak section) for narrative core.
- **Gemini video is async** — `--wait` flag waits but file may not appear for 2-10 minutes. Poll process state.
- **Cover image must be photorealistic editorial style** for sovereign-grade — dark amber, cinematic, mood captured.
