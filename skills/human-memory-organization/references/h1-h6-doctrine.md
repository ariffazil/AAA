## Post 1 (00:05 UTC) — agentic memory ladder by survival value

### Core principle
Memory should not be classified by storage technology (Redis / Vector DB / Graph DB / Files) but by **function in survival**.

### Six layers (L0–L6, function-in-survival)
- **L0 Reflex Memory** — fastest, never retrieved, always active. Hot stove / brake pedal / duck. Agent eq: safety guards, rate limits, circuit breakers, kill switches.
- **L1 Working Memory** — current context. Conversation / task / goal. Agent eq: chat context, active workflow, execution state. Expires quickly.
- **L2 Episodic Memory** — experiences. "I was there / I saw this / I did this." Agent eq: receipts, sessions, events, outcomes. **VAULT999 begins here.**
- **L3 Semantic Memory** — generalized knowledge. "Kuala Lumpur is in Malaysia." Agent eq: facts, documents, knowledge, patterns. Most vector stores belong here.
- **L4 Identity Memory** — "who am I?" father / geologist / economist / architect. Agent eq: 333-AGI / 555-ASI / 888-APEX / OpenClaw / Hermes. Changes slowly.
- **L5 Scar Memory** — the layer most agent systems miss. Failures / betrayals / losses / hard lessons. Adaptive, not pleasant. Compressed survival rules. Agent eq: postmortems, root causes, failure receipts. Often more intelligence than successful experiences.
- **L6 Constitutional Memory** — deepest, almost never mutates. Values / faith / taboos / identity axioms. Agent eq: F1 Truth, F2 Adab, F13 Sovereign, kernel invariants.

### Four-plane mapping (AAA / arifOS / A-FORGE / VAULT999)
- AAA → L1–L4
- arifOS → L6
- A-FORGE → L0–L2
- VAULT999 → L2–L5

### The most important distinction
Humans primarily remember **what changed me**, not **what happened**. A million chat messages are low value. A single scar can alter decades of decisions.

### Organism reframing
- Mind → remembers meaning
- Law → remembers principles
- Hands → remembers actions
- Witness → remembers consequences
