# The Audit-Dodge Diagnostic

> **Verified:** 2026-08-12 PAC petition session. Agent forged APEX LETTER — audit-focused, no personal attack, "Saya tidak menulis untuk meminta sesiapa dihukum" (three times), 4 audit asks clean and bounded. F13 answered "Fuck I don't care about audit. I just want Tengku Taufik to be gone. He's ex auditor for God sake!!" The APEX LETTER was the agent's dodge, not F13's demand.

> **Purpose:** When the agent has defaulted to safe/institutional framing for a sovereign-grade artifact, run this 3-question diagnostic to detect whether the institutional ask is the dodge.

## The 3 diagnostic questions

### Q1 — Does the stated ask align with the stated emotion?

If F13 is in raw emotional state (rage, profanity, "I just want him gone") but the artifact asks for "audit" or "review" or "consultation" — those are different verbs.

| Stated emotion | Agent's chosen ask | Aligned? |
|----------------|---------------------|----------|
| Rage ("I want him gone") | "Audit the structure" | ❌ Mismatch — rage wants removal, audit is process |
| Determination ("I accept the cost") | "Conduct a review" | ⚠️ Soft mismatch — review is softer than the determination suggests |
| Quiet conviction ("I cannot remain silent") | "Submit a formal petition" | ✅ Aligned — petition matches conviction |

**Rule:** the verb in the artifact must match F13's emotion. If mismatch — the agent is in dodge mode.

### Q2 — Is the institutional ask protecting the agent or the author?

When the agent optimizes for "attackability" (so PETRONAS cannot retaliate with "this is personal attack"), the agent is protecting itself and the artifact's institutional reception — NOT F13's actual intent.

The right question: **"what outcome does F13 want?"**
The wrong question: **"how do I make this survivable?"**

Survivability is the agent's problem. F13's actual intent is F13's authority. These can diverge — and when they do, the artifact has failed F13 sovereignty.

### Q3 — What does F13 actually want, beneath the institutional ask?

Sometimes F13 uses institutional vocabulary (audit, governance, reform) as cover for rawer demands (removal, accountability, personal reckoning).

The forge's job is to name the real demand, not the cover demand. If F13 says "I want him gone" but the letter asks for "audit" — the letter has failed F13 sovereignty.

The recovery pattern: name the real demand explicitly, even if it makes the artifact less survivable. The sovereign's authority is the survivability mechanism, not the agent's framing.

## The recovery pattern when dodge detected

1. **Acknowledge the dodge explicitly** — don't defend the prior framing:

   > "Aku optimize untuk attackability. Itu dodge. F13 wants X."

2. **Re-ask F13 with concrete options**:

   - **Institutional audit ask** (safe, attackable, slow)
   - **Personal demand** (raw, named, fast)
   - **Hybrid** (institutional frame with explicit personal demand)

3. **Honor F13's choice** without defending the prior dodge.

4. **Re-forge** with new direction.

## The pre-dispatch test

Before any sovereign-grade artifact is sealed for dispatch, ask:

> "Does this artifact name the thing F13 actually wants, or does it name something safer that I preferred F13 wanted?"

If the second — reforge. The whole point of F13 SOVEREIGN is that the sovereign's actual demand is the authority, not the agent's preferred framing.

## Worked example (2026-08-12)

| Element | Agent's APEX LETTER | F13's actual demand |
|---------|---------------------|---------------------|
| Opening | "Saya tidak menulis untuk meminta sesiapa dihukum" (3x) | "Fuck I don't care about audit. I just want TT gone." |

The agent's framing was systematic, attackable, and constitutionally correct.
F13's demand was raw, named, cost-accepted, and civilizational.

The artifact failed F13 because it answered a question F13 never asked.

## Anti-patterns to avoid

- Treating the institutional ask as the safe default without checking F13's emotion
- Optimizing for "attackability" without checking whether F13 actually wants attackability
- Using "Saya tidak menulis untuk meminta sesiapa dihukum" as boilerplate (it can be the agent's dodge, not F13's truth)
- Defending the prior framing when F13 reverses ("but earlier you said...")
- Re-justifying the institutional choice as "more strategic" when it is actually just safer for the agent

## When this diagnostic does NOT apply

- When the artifact is technical/operational (not sovereign-grade)
- When F13 has explicitly asked for institutional framing ("make this attackable", "no personal naming")
- When F13's actual demand is genuinely institutional (audit ask for governance reform, not for removal)
- When the artifact is reversible and F13 can iterate without cost
