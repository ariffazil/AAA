# Unified Letter Skeleton (Bahasa Malaysia) — v13.1

> Canonical template for institutional petition letters when F13 SOVEREIGN
> has signaled "ONE unified letter" (not 3-letter portfolio, not 11-iteration forge).
> Combines APEX LETTER (tenang, audit-focused) + sovereignty dimension + single
> mak anchor. Verified 2026-08-12 against `surat-final-unified` forge.

## When to use this template

Use this template when ALL of:
- F13 has explicitly stated "one letter" or "one unified letter"
- Audience is oversight body (PAC, AG, SC, NAIO) as primary recipient
- Letter must cover 3+ institutional dimensions (audit + sovereignty + governance + capacity)
- F13's voice-in-the-loop is constitutional witness (named)
- Single anchor humanity acceptable (not full 5-step grace/rupture)

## When NOT to use

- 3-letter portfolio requested (use `templates/letter-portfolio-skeleton-ms.md` if exists)
- Full mak rupture requested (use `references/grace_rupture_passage.md` 5-step pattern)
- Personal correspondence or media essay (use `templates/surat_terbuka_skeleton_ms.md`)

## Pitfalls (verified 2026-08-12)

| Pitfall | What happens | Fix |
|---------|--------------|-----|
| Forgetting defensive trio | Letter reads as attack | "Saya tidak menulis untuk meminta [X] / [Y] / [Z]" — 3 repetitions |
| Putting mak voice in opening | Document regresses to v10 biography | Move to closing single anchor |
| Naming individuals in attack mode | Reader dismisses as personal grudge | Restructure to institutional office + factual context |
| Adding INT/SPEC framings | F13 violation, conspiracy risk | Use only [OBS]/[DER]; remove all interpretive content |
| Missing constitutional anchor | Letter reads as opinion | Anchor under specific statute (Akta 269, MA63, etc.) |
| No immediate pivot after anchor | Reader carries emotional weight to signature | Add "Saya sedia hadir memberi keterangan…" after anchor |
| Sovereignty note without Perkara 8(c) | Kedaulatan dimension is incomplete | Always pair with constitutional anchor |
| 4 audits without audit-list | Letter reads as complaint, not petition | Each audit must end with 3-4 specific questions |
| Missing "saya ulangi" closing reiteration | Reader forgets the petition is audit, not prosecution | Add closing reiteration block |

## Multi-anchor test

Before submission, verify letter anchors under MULTIPLE statutes:

| Stakeholder audience | Anchor required |
|---------------------|------------------|
| PAC | Akta 269 |
| AG | Akta Audit 1957 |
| SC | Akta Pasaran Modal dan Perkhidmatan 2015 + MCCG 2017 |
| State entity (PETROS) | Akta Pembangunan Petroleum 1974 + MA63 + Perkara 8(c) |
| NAIO | PDPA 2010 / emerging AI governance |
| Foreign entity | Akta Syarikat 2006 UK + UK Companies House # |

A serious civic letter should anchor under at least 2-3 statutes simultaneously, each independently justiciable.

- [ ] Single anchor (catalyst appears ONCE only)
- [ ] Anchor reframes institutionally, not sentimentally
- [ ] Immediate pivot after anchor
- [ ] Closing reiteration ("Saya ulangi…")
- [ ] Constitutional anchors (Akta 269 + relevant)
- [ ] WPA 2010 + Article 10/8 acknowledgment
- [ ] arifOS Federation declaration
- [ ] SHA-256 with Kleene's fixed-point handled
- [ ] CC list comprehensive but bounded
- [ ] 8-12 pages
