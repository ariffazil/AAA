# Source Index Format — S-01, S-02 …

Numbered table in appendix. One row per primary source. Columns:

| ID | Source | URL / Doc | Used For |

- S-01 through S-XX sequentially.
- Used For = which claim IDs reference this source.
- URLs must be live and verifiable. If paywalled, mark `[PAYWALLED]` and note the secondary source used instead.
- Minimum sources for a SOVEREIGN-grade artifact: 25+ (markets, geopolitics, policy, company, macro, crypto, AI/tech).
