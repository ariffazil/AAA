# Item ladders, co-authorship matrix, UNKNOWN classifier

Depth for `relationship-reality-audit`. Load when the audit needs exact rungs or verdict wording.

## 1. Behavioural growth ladder

Used for touch, praise, care, contact — any dyadic behaviour. Report the **highest rung actually
evidenced**, and name every rung below it that is unreached. The asymmetry between rungs IS the finding;
a single rung is not a collapsed gradient.

| Rung | Meaning | What it requires in the record |
|---|---|---|
| L0 | no evidence | the channel does not contain it at all |
| L1 | tolerated / accepted | happened; no objection, no engagement |
| L2 | positively engaged | joked about it, responded warmly, raised it lightly |
| L3 | independently recreated the opportunity | acted, unprompted, in a context where it could recur |
| L4 | initiated / requested | asked for it, directly or in plain action |
| L5 | noticed its absence and tried to restore it | referenced the gap, worked to restore the channel |

**Rules**

- **L1 does not imply L3.** Being fine with something is not seeking it.
- **L3 does not imply L5.** Creating an opportunity is not missing it when it stops.
- **Longing lives at L5.** Any claim above L3 needs its own rung, never an inference from a lower one.
- **L0 means unmeasured, not absent.** Write "the sensor cannot see it", never "it did not happen" —
  put the distinction in the verdict line itself.
- **A display is not a solicitation.** Showing something where a reaction is legible = L3. Asking for
  the reaction = L4. Never slide one into the other because the sequence "felt like" it.
- **An oblique display is not directed at the requester.** Establish who it was aimed at before
  assigning any rung that names them.

**The inversion check.** Before writing the verdict, ask: does the record show the requester
*supplying* where the model assumed they were *seeking*? If the requester withheld the behaviour and the
other party kept showing up anyway, that is directional evidence against the model and belongs in the
verdict.

## 2. Natural-counterfactual protocol

1. Define the withdrawal threshold; apply it to **every** instance, not the longest few.
2. For each instance record: did the other party speak into the silence? how many times? unprompted?
3. Report **numerator / denominator**, plus the plainest example verbatim.
4. Separately list every direction with **no natural counterfactual available**.
5. Cap the interpretation explicitly in the same paragraph: this measures **salience**, not attachment,
   not dependence, not longing.

## 3. Co-authorship matrix

| Concept | Party A authored | Party B authored | Both **enacted** | Both **explicitly agreed** |
|---|---|---|---|---|

One row per relational concept. What to look for:

- **Authored by one, never engaged by the other** — most common. Report as *neither agreement nor
  rejection*, and say the frame has never been tested.
- **Enacted by both, agreed by neither** — the relationship works and has no name. Usually the headline.
- **Agreed by both** — rare, and almost always a register rather than a relationship category (a joking
  register, a shared routine). Identify it; it is where the pair actually lives.
- **Enacted by one, denied by the other** — a boundary, and a finding.

## 4. Three-UNKNOWN classifier

| Class | Test | Action |
|---|---|---|
| I — RETRIEVABLE | evidence exists somewhere the requester can reach | execute the retrieval now |
| II — HUMAN-PRIVATE | the answer may exist **inside** one person and has not been volunteered | never infer; only they can supply it |
| III — UNCREATED | no shared answer exists because neither party has ever made one | no retrieval resolves it; it requires a conversation |

**Why the distinction matters:** CLASS II invites more searching. CLASS III does not. Reporting a
CLASS III question as CLASS II is the failure that keeps an audit running forever.

**Verdict wording:**

- CLASS I → name the artefact and the hand that can fetch it.
- CLASS II → "may exist; not readable from here; only they can say it."
- CLASS III → "the archive cannot answer this, because the question has never been put. It is not
  hidden. It is unmade."

## 5. Contamination graph

```
[fiction / persona]     ─┐
[population literature] ─┤→ AI synthesis → later memory → claim cited as fact
[agent commentary]      ─┘
```

Build it whenever a persona or literature packet predates the audit. Then **name the mechanism**: a
fictional shape and a population-level finding shared a structure, and the structure was read back onto
a real individual. The mechanism recurs; the specific artefact does not.
