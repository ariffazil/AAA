# Basin Thermal Maturity — Quick Check

User is a petroleum geologist. When asked "does this basin have oil/gas?" — answer the thermal question FIRST.

## Sequence (do this BEFORE describing stratigraphy)

1. **Source rock exists?** — organic-rich sediment (TOC > 2%, Type II kerogen). If NO → basin is dead. Stop.
2. **Burial depth** — total sedimentary section above basement (m)
3. **Geothermal gradient** — depends on crustal type:
   - Oceanic crust (~7km): 25–30°C/km
   - Continental (thinned): 23–25°C/km
   - Note: carbonate-rich columns dissipate heat faster (high thermal conductivity ~2.8 W/mK vs shale ~1.8)
4. **Bottom-hole temperature** — seafloor (~28°C tropics) + (section thickness × gradient)
5. **Maturity windows:**
   - Onset oil: 60–65°C
   - Peak oil: 90–110°C
   - Wet gas: 110–150°C
   - Dry gas: >150°C
6. **Verdict** — if base of section < 90°C → CANNOT COOK. Regardless of what else is there.

## Common mistakes

- Leading with "2000m of Tertiary carbonate" when asked if it can cook — that's stratigraphy, not the answer
- Assuming equatorial = hot = mature — conductivity matters more than surface temperature
- Ignoring volcanic basement as hard floor — nothing below = no deeper source kitchens
- Counting dry wells as anomalies — 19 wells without discovery is data, not bad luck

## Reference cases

- **Maldives:** 2–2.5km section, 25–30km thinned continental crust, carbonate-dominated → 85°C at base → below oil window. Shell drilled one well (ARI-1, 1991), hit basement. Kerala-Konkan (same ridge): 19 wells, 6207m max depth, zero commercial discoveries.
- **Kerala-Konkan Basin (India):** same Laccadive Ridge system, 19 wells drilled by ONGC, zero commercial. ₹1,495 crore spent. NDR India: KKD-1 = Dry. Empirical proof that the thermal system doesn't work.
