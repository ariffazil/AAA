# Pre-Comp Battle Plan — PDF Pattern for Coach's Athlete

> Class pattern for pre-competition "battle plan" guides (proven 2026-09-01: Amir → Mr KL 2026, 5-6 Sept, TLKB Kepong, KLBBF).
> DISTINCT from post-comp brief (see `README_postcomp-poster-amir-2026-08-29.md` in substrate) and from `pre-stage-wisdom.md` (final 30-min card). This is the WEEK-level strategic guide.

## Trigger

- Arif says "bagi dia guide", "battle plan", "agentic intelligence guide", "wisdom card" for an athlete BEFORE a comp.
- Arif names the athlete + the comp + asks for a PDF the athlete can "cognitively ingest".

## Deliverable shape

- **Format:** multi-page A4 PDF (7 pages proven), dark bg `#0a0a0a` + gold `#f0a500` SyedOS brand, DejaVu Sans. Build HTML → weasyprint → verify (`file` = PDF 1.7, `pdfinfo` page count matches designed `.page` blocks).
- **Language:** Bahasa Melayu, Coach Syed register (imperative, "hang"/"kau", English gym jargon, hard truth, ZERO mushy affirmations).
- **Boundary (load-bearing):** the draft speaks in Syed's voice but is a DRAFT — Syed's final approval required before it reaches the athlete. Always flag this in the delivery message to Arif. Frame every protocol item as "ikut apa coach dah set" — the agent never prescribes macros/training as its own authority.

## Section structure (7 pages)

1. **Cover** — event, athlete, coach, one-line mission ("Naik stage. Tunjuk versi paling tajam. Biar judge nampak apa coach nampak.").
2. **01 · Intel Event** — verified facts ONLY (name, dates, venue, organizer, scale). Include venue reality from prior shows (e.g. TLKB = car-park style, gym-light ≠ stage spot). "Timing penuh ikut jadual organizer — coach akan confirm" — NEVER invent schedule splits.
3. **02 · State of Play — Hard Truth** — honest gaps from the athlete's LAST comp stage read (from substrate `sessions/<athlete>.md`), framed as "yang judge nampak" + "boleh kau control: kering, posing, keyakinan". No fake praise, no shaming.
4. **03 · Minggu Ni (5-day protocol)** — coach's plan framing: ikut apa coach set, zero cheat, tidur 8 jam, no extra cardio, pump-focused training on weak points, posing 2×/day.
5. **04 · Posing** — mandatories grid + drills targeting the athlete's SPECIFIC weak points (e.g. lat flare drill: siku tinggi, tolak lat bawah keluar, hold 5 saat, simpan angle yang jumpa). Eye contact, hold 3-5s, no rush transitions.
6. **05 · Hari-H Backstage** — table: sampai venue / pump room 15-20 min (bukan 1 jam) / air sip / oil touch-up / trunks spare / stay warm antara rounds / panggilan / comparison. "Orang kau handle — hang fokus stage."
7. **06 · Judge + Mindset** — 30 saat judge tengok; kekeringan dulu, bentuk lepas, persembahan terakhir. Winner doctrine: kau lawan kau semalam; tak menang = data bukan hukuman; debrief 48 jam.
8. **07 · Pocket Checklist** — beg (trunks + spare, tan, oil, towel, water, snacks, charger, slip + IC, coach number), timeline table, "3 Peraturan Besi" red block (jangan improvise / jangan tengok skrin / jangan banding).

## Back-to-back show pattern (proven)

Athlete comped <1 week prior (e.g. Enrich 29/8 → Mr KL 5/9): the guide's core message = **momentum, bukan rebuild**. "Bukan nak tukar badan dalam 5 hari. Nak tukar persembahan." Target display sharpening (dryness presentation, back lat flare, pump timing on weak points), never body changes. Reference the prior show's competitor number + gaps explicitly — the athlete has stage evidence to anchor on.

## Anti-fabrication constraints

- Category: assume from last comp but FLAG ("kalau Mr KL pecah kategori lain — tanya coach, jangan teka"). Never assert without source.
- Schedule split (weigh-in day vs prejudging vs finals): keep generic "ikut jadual organizer" unless verified.
- Venue/scale/prize numbers: only from verified intel (`references/msia-physique-events-2026-2027.md` or web-search OCR text).
- Voice: forbidden "you got this" / "believe in yourself" — hard truth and imperative only.
