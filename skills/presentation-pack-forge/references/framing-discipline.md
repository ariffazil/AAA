# Framing Discipline — Authority Without Evidence

Forged: 2026-08-13. Lesson from Bekok Deep-1 deck.

## The Failure

Built a 6-slide PPTX about "The Cost of a Forgotten Well" that named a real well
(Bekok Deep-1), used "WITNESS REQUIRED" language, and "HOLD remains open" — but
contained zero factual evidence (no chronology, no sources, no epistemic labels).

Result: a technically perfect artefact that implied accusation without basis.

A human reader would fill the gaps with their own narrative. The artefak would become
whatever the reader imagined — not what was intended.

## The Rule

Before any artefact carries names of real entities (people, wells, companies, events):

1. **Declare the artefact type upfront** — one sentence, above the fold:
   - Reflection: *"This is not an incident report. It is a reflection on how
     institutions remember outcomes while individuals remember consequences."*
   - Investigation: must carry chronology, sources, epistemic labels (OBS/DER/INT)
   - Testimony: must carry witness identity, date, and verifiable claims

2. **Match language authority to evidence depth**:
   - `WITNESS REQUIRED` + zero evidence = **VOID** (false authority)
   - `REFLECTION` + named entity as emotional anchor = **SEAL** (honest framing)
   - `INVESTIGATION` + full evidence chain = **SEAL** (honest capability)

3. **The framing sentence is load-bearing**. It changes reader frame entirely:
   - Without: reader assumes investigation → expects facts → finds none → distrust
   - With: reader understands reflection → accepts philosophy → finds power

## Decision Matrix

| Artefact uses named entities | Has evidence chain | Framing sentence | Verdict |
|---|---|---|---|
| Yes (real wells, people) | No | No | **VOID** — implied accusation |
| Yes (real wells, people) | No | Yes ("reflection on...") | **SEAL** — honest philosophy |
| Yes (real wells, people) | Yes (OBS/DER/INT) | Yes ("investigation of...") | **SEAL** — evidence-grounded |
| No (archetype/analogy) | N/A | Optional | **SEAL** — universal principle |

## Boundary Vocabulary Translation (Forged 2026-08-13)

Internal governance vocabulary must be translated at the human boundary. Sigils
that make sense in the agent layer become false authority on a human-facing artifact.

| Internal sigil | Agent meaning | What a human infers | Safe human translation |
|---|---|---|---|
| WITNESS REQUIRED | "agent must route to witness layer" | Official investigation with evidence | Omit, or use artifact-appropriate tagline |
| HOLD | "unresolved governance state" | Something is being covered up | "A question left open" |
| SEAL | "constitutional closure, hash-chained" | Legal-grade attestation | Omit unless actually sealed |

**Rule:** Scan every human-facing artifact for internal governance terms before
delivery. Replace with human language that matches the declared genre.

**Corollary:** If you used "WITNESS REQUIRED" on an artifact with no evidence,
you have created false authority. This is worse than fabrication — it is
fabrication-adjacent because the reader's mind fills the evidence gap.

## The Reality Bridge Test

A deck passes the reality bridge test when:

> Visitor opens page → Downloads PPT → Reads all slides → Understands lesson
> → Without ever talking to Hermes

If understanding requires the chat session, the bridge failed.
If understanding survives independently as an artifact, the bridge passed.

## PPT/PDF as Constitutional Boundary Objects

PPT and PDF are not productivity formats. In the edge bridge architecture:

| Layer | Function | Artefact |
|---|---|---|
| Narrative | Chat / conversation | Tokens |
| Decision | Coordination object | PPT |
| Witness | Attestation object | PDF |
| Consequence | Immutable seal | VAULT999 |

PPT = COORDINATE (mutable, proposed — humans negotiate on it)
PDF = WITNESS (fixed, witnessed — institutions accept it)
SEAL = CONSEQUENCE (immutable, hash-chained — cannot be undone)

Without PPT, Hermes cannot persuade.
Without PDF, Hermes cannot attest.
Without both, the Reality Bridge is incomplete.
