## Why each stage happened

- **Stage 1 → Stage 2:** Reorg. "web unification rename" consolidated the
  personal arif-sites into the unified `arif-fazil.com` repo. The chat
  interface was replaced by a marketing landing appropriate for a public hub.
- **Stage 2 → Stage 3:** "Agentic web optimization." The 5-stage 2026-08-09
  Caddy change routed `/world/makcikgpt/*` static-first (so AI crawlers get
  full HTML without React hydration). The landing page was regenerated by
  `generate-makcik-index.cjs` from `essays.json`, optimized for text-only
  crawlers (canonical landing path, source-of-truth file path, generator
  script name all in the footer). The Primer Dark visual identity was
  dropped in favor of compact agent-friendly metadata.

## The Caddy intercept that breaks the SPA

The SPA component `src/pages/MakcikGPT.tsx` (134 lines, full Primer-Dark-
style hero + 999 SEALED badge + article cards) is human-friendly. **It is
never served to humans**, because the Caddy routing for `/world/makcikgpt/*`
serves `try_files {path} {path}.html {path}/index.html /spa-shell.html =404`
from `/var/www/html/arif/makcikgpt-md/` BEFORE the request ever reaches the
SPA fallback. The static `index.html` in `makcikgpt-md/` is what's served to
both bots AND browsers.

This is the same routing class that produced the
`references/makcikgpt-static-surface.md` lesson — when static-first routing
is applied to optimize for crawlers, the SPA's human-friendly design becomes
dead code.

### Layer 2 — DESIGN_INVARIANTS.md (the design SOT)

Wrote `/root/arif-fazil.com/sites/arif-fazil.com/DESIGN_INVARIANTS.md` —
a single canonical document declaring:
- **The Rule:** "Every visual page must pass the 3-second human test"
- **Allowed:** hero text with persona voice, persona signature footer,
  series/category badges, date stamps in human-readable form
- **Forbidden:** "Canonical landing:", "Source of truth:", "WHERE AM I?",
  "WHY CARE?", "Rendered by", F-prefix codes, epistemic tags in body,
  `llms.txt · missions.json · surfaces.json` in visual footers
- **The 5 Rein:** the exact 5 forbidden strings that fail the lint
- **Per-surface visual contracts** for landing + article + essay
- **Where to find archived "good" versions** (Primer Dark at `767596c`,
  minimal essay page at `75dcd84`)

This is the SOT for every future agent touching the site's visual layer.

### Layer 3 — `scripts/design-lint.sh` (enforcement)

Wrote `scripts/design-lint.sh` — bash script that scans `public/` and

## Key detection recipe — find design regressions early

```bash
# 1. Pull the live landing and grep for institutional chrome patterns
curl -s "https://arif-fazil.com/world/<hub>/" | \
    grep -E "(Source of truth|Rendered by|scripts/|\\.cjs|generated/|<canonical>)"

# 2. If 2+ matches → institutional chrome has leaked to a human surface
# 3. Run DEEP ARCHIVE EXTRACTION pitfall to find the previous design
# 4. Decide: restore old chrome to static, OR redesign static, OR rewire Caddy
```
