The federation runs **126 skills** in AAA canonical. They used to be sorted by prefix (AGI, ASI, APEX, AUDIT, FORGE, RSI, KERNEL, MEMORY, OBSERVE, ATLAS). That made them hard to ask about — you couldn't easily find "all skills about skill evolution" without knowing the prefix.

This taxonomy sorts by **what the skill actually does** so an agent can load the right one without remembering naming conventions.

## HOW TO USE THIS INDEX

```
1. Identify what you need to do
2. Find the section in this index (I-VII)
3. Load the skill by name
4. Follow its protocol
5. If the skill doesn't exist for your task: forge one (FORGE-skill-creator)
6. If the skill diverges across agents: run RSI-federation-mesh
```

**Federation-wide health check** → `AUDIT-agent-skill-mesh`
**Session-end recursion** → `RSI-recursive-improvement`
**Cross-agent federation recursion** → `RSI-federation-mesh`
