# MIT Brain Network Study — Interpretation Reference

## Source

MIT study (2026), Journal of Neuroscience. Led by Evelina Fedorenko.
fMRI data from 772 participants.

## Key Findings [OBS]

1. **17 additional language-responsive regions** beyond classic Broca's/Wernicke's areas
2. **5% of brain volume** = all language regions combined ("size of a large strawberry")
3. New regions: cerebellum (5 areas), hippocampus, amygdala, medial frontal cortex, lower temporal lobe
4. Some regions are "bridge" areas responding to both language AND general cognitive tasks
5. Earlier studies missed these because they averaged fMRI across participants, blurring individual patterns
6. Fedorenko's team used individual brain patterns + lower statistical thresholds + weaker-signal regions

- Correct enough for most cases
- Easy to teach, publish, replicate
- When compression is too successful, it starts filtering what counts as data
- New data dismissed as "noise" because canonical model already won

## Interpretation: Cerebellum as Prediction-Correction Engine [INT]

Cerebellum doesn't just coordinate — it builds **internal models**:
- Predict what should happen
- Compare with what actually happens
- Adjust

If language is processed in cerebellum:
- Language = continuous prediction stream
- Ambiguity = high prediction error (uncomfortable)
- Poetry = prediction fulfilled in unexpected ways (beautiful)
- Irony = prediction deliberately violated for new meaning

**Implication:** Language is not symbols stored. Language is a stream of predictions continuously corrected. You can't understand language by studying structure — you must study trajectory.
