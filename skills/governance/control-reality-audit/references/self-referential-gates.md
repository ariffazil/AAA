# Self-referential gates — when the control can be satisfied by deleting what it audits

## The mechanism

A content-matching control reads text and flags a match. Nothing in that design distinguishes:

- the author **asserting** the flagged thing,
- the author **quoting someone else's** flagged thing,
- the author **describing the control that flags it**.

So the cheapest way to clear the gate is to remove the match — and the match is often the evidence. A constraint meant to protect content becomes a mechanism that deletes it.

The tell is an exemption that covers most rules but not the one in play: if quoted matter is downgraded to a notice for every bank **except one**, that exception is not an oversight, it is the live defect. Test it by running the tool against the document that defines it. When the law's own source fails its own instrument, the instrument is scoped wrong.

## When a gate blocks you for carrying a trigger string

**Bisect the trigger before anything else.** Probe with the smallest possible payloads, one variable at a time, until the exact blamed token is isolated. Do not guess, and do not rewrite the whole document hoping it clears.

```
minimal probe A -> blocked?
minimal probe B -> blocked?
... narrow until ONE word flips it
```

Then choose:

- **Change register, keep substance.** If the blame is a figurative use of a domain word — a word whose literal sense belongs to money, health, legal or trading — substitute a neutral synonym for the figurative sense. Meaning unchanged; false positive gone. This is register, not evidence.
- **Never change evidence.** Do not delete a quotation, soften a fact, drop a number, or remove a citation to clear a gate. If the gate can only be cleared that way, **leave it blocked** and report the true state — blocked at the gate, with the exact blocked operation and why. A green gate bought with lost evidence is worse than a red one.
- **Do not retry the same payload.** A constitutional gate that blocks is not a transient error; retrying as-is is the loop the gate exists to stop.

## What to report when blocked mid-task

1. The state actually reached: blocked at the gate, the exact operation, the matching pattern.
2. What the blocked artifact contains and why it is needed.
3. That you did **not** alter the content to pass — and that this was deliberate.
4. The lane that can unblock it: package the exact mutation (command + target + why) and request the seal, or delegate to an execution seat with the same package.

The blocked artifact is itself evidence for the audit you were writing. Record it.

## Why this outranks the bug

A control that induces its operators to hide evidence does not merely fail to protect anything — it degrades the record silently, because the passing gate looks like success. Watch for it in any sweep whose output is graded by a matcher, and say it plainly when you find it: the failure is not the blocked document, it is the instruction the tooling taught.
