## 2 · Proposed epistemic visual canon (verbatim from proposer)

### 2.1 Strict CSS matrix for epistemic tags

| Epistemic State | Core Definition | UI Rendering Rule (Dark Mode) |
|---|---|---|
| **OBS** (Observed) | Hard factual baseline. Raw data. | Solid geometric tag. **Yellow** accent. Sharp, unbroken borders. |
| **DER** (Derived) | Mathematically processed from OBS. | Solid geometric tag. **Blue** accent. Unbroken borders. |
| **INT** (Interpreted) | Human or Agent reasoned output. | Outlined tag. **Red** accent. Solid border, transparent core. |
| **SPEC** (Speculative) | High uncertainty / forecasting. | Hatched/Dashed geometric border. Blue (or grey) hatch. No solid fill. |

**Implementation note:** Absolutely no organic shapes, gradients, or human figures in widget thumbnails. Pure data geometry.

### 2.2 Operational state consistency

Unify operational metadata. Every card must explicitly state its deployment readiness.

| Tag | Meaning |
|---|---|
| `[PROD]` | Production-deployed |
| `[BETA]` | Beta-stage, not for primary use |
| `[MOCK]` | Mock data only |
| `[INTERACTIVE]` | Live rendering tool |
| `[STATIC SPEC]` | Spec sheet only, not interactive |

**Fix:** No more mixing of "OPEN SPEC ↗", "Widget preview", "live render" without explicit state tag.

## 3 · Architecture options for 18-card grid (verbatim from proposer)

| Option | Architecture | Pros | Cons |
|---|---|---|---|
| **A. Default Filtering (Domain)** | Gallery defaults to showing ONLY LOGS or SEISMIC on load. User clicks filter pills to see others. | Immediate drop in ΔS; clean focused entry | User might not realize 18 tools exist unless they click ALL |
| **B. Epistemic-First Grouping** | Abandon domain grouping. Group widgets strictly by highest epistemic risk ("Pure OBS Tools", "INT & SPEC Tools"). | Reinforces F2 truth boundary visually; forces users to understand tool risk | Unconventional for geoscientists who search by domain (e.g. "Map" tool) |
| **C. Accordion / Toggle Lists** | Notion-style toggles by domain. All toggles closed by default except most critical one. | Maximum structural density; fast scanning | Reduces visual impact of widget thumbnails |

**External recommendation:** Option C (structural density, low entropy).
