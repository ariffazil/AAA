## Witness Status Legend

- **WITNESSED** — Running service, operational history, proven function
- **PARTIAL** — Function exists in code but name is new or lacks dedicated service
- **BY DESIGN** — Deliberately unwitnessable (by definition)
- **ASPIRATION** — Named concept with no corresponding service or observable behavior
