## 3. Scar falsification

### 3.1 "vision is BLIND on some lanes and falls back silently" — FALSIFIED FOR `mcp__aforge__forge_visual_qa`

The scar claimed A-FORGE's `forge_visual_qa` sometimes returns `deviations:[]`
(an empty deviation list, status `CONFIRMED`) without actually having read the
pixels. I predicted that the returned `screenshot_hash` field is `sha256`
of something path-only, then ran the falsification: feed it different image
files at the same path, and see whether the hash tracks the path or the bytes.

**Conclusion:** `screenshot_hash` is **always** `sha256(abs_path_string)`,
not the bytes of the image. The W¹ "vision" witness is therefore a
**hash-of-path** oracle, NOT a vision oracle — every call returns
`status: CONFIRMED, deviations: []` regardless of what's in the file. The
sibling W² linter does the real work (and rejects images that don't carry
the text the DOM payload asserts). The "vision" channel is blind by design
on this tool today; the scar was correct, and the fallback is silent
because the tool always returns CONFIRMED.
