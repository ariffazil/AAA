## Phase 1 — repairs made (minimum metadata only)

### 1A · arifOS `observatory_snapshot`

Contradiction: labelled `protocol: "mcp"`, absent from arifOS's 9 live MCP tools, while its path
`/api/observatory/v1/snapshot` answers HTTP 200.

Action: `protocol` field changed `"mcp"` → `"http"` in the **site source of truth**
`/root/arif-fazil.com/sites/arif-fazil.com/public/.well-known/capabilities.json`.
Capability identity preserved (`name`, `description`, `path` untouched). Not classified dead.
Handler and endpoint not modified. Diff is exactly **+1/−1 line**.

A first attempt at this patch rewrote the file through `json.dump` and silently escaped 24
non-ASCII characters (`—` → `\u2014`, `Ω` → `\u03a9`). That was reverted with
`git checkout --` and redone as a surgical single-field text edit. Recorded in the ledger.

Why the site source and not the live file: `capabilities.json` is generated by WEALTH
`scripts/sync_manifest.py`, which reads this file and carries it forward. Patching the live copy
would be clobbered by the next generator run, and writing to `/var/www/html` is a deploy.
`sync_manifest.py` is **not** on any cron (checked: `/etc/crontab`, `/etc/cron.d/`,
`/root/HERMES/cron/jobs.json`, root crontab), so this patch does not self-deploy.
