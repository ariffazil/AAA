3. The Original Intuition

The sovereign's intuition, in his words: "it's the first act of creation, right? And agents must know how to create a correct title for file name?"

The careful answer (established across the session):

Naming is not the first act of physical creation. It is often the first act of durable epistemic address formation — the point at which a distinction becomes repeatable, communicable, contestable, governable, and persistent. Reality may precede the name; coordinated intelligence cannot act on what it cannot address.

And the boundary that makes the intuition safe instead of dangerous: naming is constitutive where it establishes shared meaning, identity, relationship, role, category, or institutional obligation; it is declarative only where it claims a governance-state transition has occurred — there it creates the claim, never the validity. 10. Naming Doctrine for Agents and Files

10.1 The four layers of a name

10.2 The ratified boundary (Naming-Doctrine Axiom 4, Register Scope)

Naming is constitutive where it establishes shared meaning, identity, relationship, role, category, or institutional obligation, bounded by the authority, participation, and consent applicable to the named relation. Naming is declarative only where it claims that an evidentiary, authorization, acceptance, execution, or governance-state transition has occurred. In that register, the name creates the claim, not the validity of the claimed state. A witnessed and authorized event remains necessary.

10.3 File naming — what actually changes retrieval

Use names that carry date · subject · type · version · status where the file travels outside version control: 2026-10-19_governed-reference_session-closure_v01.pdf. Inside git, prefer stable names and let history carry versions. Status words in names are navigation metadata, never governance evidence. The grammar that already works on this VPS (date-first forge_work/ dirs, timestamped .bak.20260804-oauth-off) should simply be made uniform — no new registry required. INT

11. Why Questioning Is Core to Intelligence

Questioning is the mechanism that converts ignorance into directed search. A question partitions the possibility space; the answer collapses part of it; judgment improves. Formally, question value is expected judgment change: V(Q) = E[ΔJ | Q], where J is the judgment state — and "change" is material across six surfaces: verdict, confidence, scope, authority map, reversibility assessment, permitted action. A question whose plausible answers move none of these is extraction or paralysis, not intelligence. INT

This session is a live demonstration: the question "is naming worth thinking about?" became "is the naming doctrine enforced?" became "has the enforcement tool ever run?" — and that last question found a 21-day dead sensor. Knowledge inventory would have stopped at "the doctrine exists".

Stopping rule: stop asking when further answers cannot change model, judgment, or action — decision-equivalence, not omniscience (the irreducible unknown floor Ω₀ ∈ [0.03, 0.05] is canon). Levels 4–5 of the question ladder — ask constitutionally, know when to stop — are already binding law in this federation: the Question Routing Law (F13, 2026-09-13) and agent-question-budget (absorb complexity; never export thinking cost to the sovereign).

17. Stopping Rule

A name is worth thinking about exactly when its shape changes retrieval, interpretation, coordination, or consequence. Two names that induce identical behaviour in all four are decision-equivalent — take the simpler one and return to work.

The same rule governs questioning (stop when answers cannot change judgment) and verification (stop when further checks cannot change the verdict). In this federation, naming demonstrably changes behaviour — the 666/888 dispute, the G-formula collision, the 30 version-sibling pairs all had real consequence — so the thinking was warranted. Past the decision-equivalence line: bikeshedding. INT
