## 1 · Three F13 Sharpenings (Penajaman)

### P1 — Witnessed, not Reported

Original formula `Health = Adaptation / Debt` has a constitutional defect: actor reports its own numerator, its own denominator, and grades itself. Same defect we reject for scars (`scar sah bukan kerana diisytihar, tetapi kerana disaksikan`).

**Rule:** All health indicators MUST be witness-derived. Numerator and denominator both witnessed by independent substrate.

```text
Adaptation Claimed  ≠  Adaptation Witnessed
Debt Claimed        ≠  Debt Witnessed
```

**Operational consequence:** any agent-reported metric (mutation count, scar count, audit count) without independent witness is provisional, not constitutional. M_min audit per scar-2026-10-01-002 already enforces this for cross-model independence.

### P2 — Trend-state, not Scalar

`Health = 0.0437` looks scientific but mixes heterogeneous units (mutation count vs weighted contradiction score). Replace scalar with ordinal trend:

```python
if debt_growth > adaptation_growth:     DECAYING
if debt_growth ≈ adaptation_growth:     STABLE
if adaptation_growth > debt_growth:     REINFORCING
```

**Rule:** Health = ordinal state from trend comparison, not single scalar ratio. Anti-fake-precision. Ratifies the anti-sink meta-rule for v1.

## 3 · Two Types of Debt

### Type A — Reality Debt (genuine failure)

- unresolved contradiction
- orphan HOLD (work item without owner)
- ignored signals
- forecast never verified

This is debt that means decay.

### Type B — Growth Residue (construction cost)

- institutional formation
- successor design
- canon consolidation
- transition uncertainty

This is debt that may be unavoidable cost of building.

**The real question is not "does debt exist?" but "does debt decay back into learning?"**

- If FI-007 is inspected and produces mutation: debt eaten.
- If not: debt becomes scar without learning — the worst outcome.
