## Six operational loops

### 1. Vision to mission

A human objective enters via AAA as a bounded mandate, not a vague “make the system better” instruction.

```text
ARIF intent
  → AAA identity-bound mission
  → arifFLOW route and checkpoint plan
  → arifOS INIT / OBSERVE / THINK
  → domain-specific evidence task
```

A valid mission needs:

- A human owner and authority scope.
- A purpose that can be checked against reality.
- Known constraints, affected stakeholders and prohibited outcomes.
- A declared domain and expiry.
- A success measure that is not merely “agent says completed.”
- A rollback or stop condition for any material action.

Example:

```text
Bad mission:
“Improve GEOX automatically.”

Governable mission:
“Within a shadow environment, investigate why GEOX parity checks diverge
between two known execution paths. Produce evidence, candidate reversible
remedies, and a before/after test plan. Do not alter deployment, memory
authority, scheduler cadence or production configuration.”
```

### 2. Exploration loop

This is where agents investigate the present world before dreaming about the future.

```text
Reality
  → arifOS arif_observe
  → evidence objects with provenance, timestamp and ontology
  → domain agents analyse within their lane
  → arif_memory retrieves relevant, allowed prior context
  → arifOS arif_think structures claims, assumptions and unknowns
  → ACD /dream only if counterfactual exploration adds value
```

The discipline is:

```text
OBSERVED ≠ INFERRED ≠ SIMULATED ≠ NORMATIVE ≠ UNKNOWN
```

A log, test result, Git object, health probe or human observation may support an `OBSERVED` claim. A diagnosis based on it is `INFERRED`. ACD branch outputs are `SIMULATED`. Constitutional floors are `NORMATIVE`. Missing evidence remains `UNKNOWN`.

This prevents a known federation failure mode: the system retrieves its own prior narrative, treats it as evidence, and recursively amplifies it into a false institutional belief.

### 3. Dream and counterfactual loop

ACD is the **pre-execution possibility organ**. Its function is not fantasy; it is structured, bounded future exploration.

```text
Grounded evidence bundle
  → ACD /dream
  → generate multiple materially different branches
  → identify assumptions and divergence points
  → stress-test failure and unintended-consequence branches
  → preserve dissent and contradiction objects
  → score only within declared validity limits
  → emit Dream Receipt
  → return a proposal or question, never execution
```

A correct ACD output says:

```text
SIMULATED:
“If the parity check is moved to canonical path X, the mismatch may decline.

ASSUMPTIONS:
- Path X is truly canonical.
- Existing test coverage captures the divergence.
- No unseen consumer depends on the legacy path.

COUNTER-BRANCH:
“Moving the check may conceal a deeper provenance defect.”

UNKNOWN:
- Whether production agents call the same path.
```

It does **not** say:

```text
“The canonical fix is X. Apply it.”
```

ACD’s value is not only choosing a branch. Its deeper value is revealing what must be measured before the federation earns the right to choose.

### 4. Judgment and execution loop

The selected proposal does not go directly from ACD or a domain agent into A-FORGE.

```text
Proposal + evidence + Dream Receipt
  → arif_memory audit / provenance inspection
  → arifOS arif_judge
  → verdict: SEAL | HOLD | SABAR | VOID
  → ARIF confirmation if irreversible/material/critical
  → arifFLOW authorised checkpoint
  → A-FORGE bounded execution
  → execution receipt and rollback evidence
```

The hard separation:

```text
AAA routes.
arifFLOW transports and checkpoints.
ACD imagines.
Domain agents propose.
arifOS judges.
ARIF authorizes consequential closure.
A-FORGE executes.
```

If one agent can perform all seven functions without independently enforceable boundaries, it is not a constitutional federation. It is one model wearing several labels.

## Memory and learning

### Memory is not learning

`arif_memory` is a **governed memory governor**, with a canonical public role of querying and managing institutional memory. Repository materials describe it as a L1–L6 semantic recall, storage and persistence capability, with canonical `arif_memory` replacing legacy `arif_memory_recall` naming. [github_mcp_direct]

But storing an event is not the same as learning from it.

| State | Meaning | Is it learning? |
|---|---|---|
| Log exists | An event was written somewhere | No |
| Receipt exists | A process claims something occurred | No—until validated |
| Memory record exists | Content is retrievable later | No |
| ACD branch exists | A possible future was generated | No |
| Test passed | A specific check succeeded | Not necessarily |
| Rule/config changed | Behaviour might now differ | Still incomplete |
| Later decision changes because of a witnessed result | The system retained a causal lesson | **Yes, candidate institutional learning** |
| Later outcome validates or corrects that change | The lesson was tested against reality | **Stronger learning** |

### The learning chain

```text
1. Witness
   Something happened in reality.

2. Interpretation
   An agent forms a bounded, evidence-linked explanation.

3. Candidate delta
   AIO proposes a narrow change to a rule, configuration, test,
   routing policy, or operational playbook.

4. Constitutional judgment
   arifOS evaluates authority, evidence, reversibility and floors.

5. Human ratification
   ARIF confirms when the transition crosses the required threshold.

6. Enforcement
   A-FORGE applies the exact approved change with rollback.

7. Consequence measurement
   arifFLOW and observers collect before/after evidence.

8. Reconciliation
   Did outcome match the forecast? Did a new harm appear?
   Did the change actually alter future behaviour?

9. Retention
   arif_memory retains an outcome-linked lesson with lineage.

10. Seal
    arif_seal / VAULT999 preserves the finished causal chain.
```

That is the proper meaning of **recursive improvement** in arifOS: not uncontrolled self-modification, but repeated, reversible, evidence-calibrated improvement of bounded operational capability.

## Self-healing, correctly defined

“Self-healing” must be narrow. It cannot mean an agent silently rewrites anything it dislikes.

| Healing tier | Example | Default authority |
|---|---|---|
| **T0 — Detect** | arifFLOW notices missed checkpoint; WELL detects degraded service; audit finds a dangling path | Automatic observation allowed |
| **T1 — Contain** | Stop retry storm, isolate failed queue, mark dependency unavailable, fail closed | Automatic only if pre-authorized, reversible and within blast-radius limit |
| **T2 — Diagnose** | ACD explores causes; agents collect logs; G0-A maps contradiction | Read-only inquiry allowed |
| **T3 — Propose repair** | AIO creates repair petition with evidence, test and rollback plan | Proposal only |
| **T4 — Apply reversible repair** | A-FORGE changes one configuration or shim in a controlled branch | Needs SEAL and authorized scope |
| **T5 — Deploy or alter policy** | Enable service, modify production routing, adjust threshold, change memory authority | `888_HOLD` and ARIF decision |
| **T6 — Constitutional amendment** | Change floors, sovereign controls, interpretation authority | Human-only constitutional process |

This makes the phrase accurate:

> The federation can **detect, contain, diagnose and propose** autonomously within policy. It can **repair** only under bounded authorization. It cannot self-amend its constitution.

## What “agentic intelligence” means here

**CLAIM:** In your architecture, agentic intelligence is not model IQ. It is the federation’s ability to reliably coordinate sensing, evidence handling, counterfactual exploration, judgment, bounded action, consequence measurement and retained learning under explicit authority boundaries.

A useful functional formulation is:

\[
\text{Institutional agentic intelligence}
=
\text{Sensing}
+
\text{Reasoning}
+
\text{Possibility exploration}
+
\text{Governed memory}
+
\text{Authorized action}
+
\text{Outcome calibration}
\]

But this only works if every term is operationally real:

- **Sensing** must read actual state, not stale dashboards.
- **Reasoning** must expose evidence and uncertainty.
- **ACD** must keep imagined branches `SIMULATED`.
- **Memory** must preserve provenance and prevent truth-class leakage.
- **Judgment** must be distinct from proposal.
- **Execution** must be scoped, logged and rollback-capable.
- **Learning** must be measured against consequence.
- **Human sovereignty** must be enforceable, not ceremonial.
