# Cognitive Typing Guide — Public Figures

## When to Use

When analyzing a corporate or government leader's public communication to understand their cognitive type and how it interacts with their role.

## The Framework

### Step1: Map Communication Patterns

| Pattern | Cognitive Indicator |
|---------|-------------------|
| Financial framing for everything | T (Thinking) + S (Sensing) |
| Precise numbers, vague operations | S (Sensing) over N (Intuition) |
| Rehearsed deflection, no fumbling | J (Judging) over P (Perceiving) |
| Internal focus, institutional language | I (Introversion) over E (Extraversion) |
| Visionary, strategic, challenges status quo | N (Intuition) + T (Thinking) = NT |
| People-focused, empathetic, values-driven | N (Intuition) + F (Feeling) = NF |
| Action-oriented, spontaneous, adaptable | S (Sensing) + P (Perceiving) = SP |
| System-focused, procedural, reliable | S (Sensing) + J (Judging) = SJ |

### Step2: Identify the Type

The4 SJ types (Guardians):
- ISTJ: "The Logistician" — reliable, detail-oriented, procedural, resistant to change
- ISFJ: "The Defender" — protective, warm, meticulous, avoids conflict
- ESTJ: "The Executive" — organized, decisive, traditional, authority-focused
- ESFJ: "The Consul" — sociable, caring, traditional, harmony-seeking

The4 NT types (Rationals):
- INTJ: "The Architect" — strategic, independent, visionary, systems-thinker
- INTP: "The Logician" — analytical, theoretical, innovative, detached
- ENTJ: "The Commander" — decisive, strategic, leadership-oriented, efficient
- ENTP: "The Debater" — innovative, intellectual, versatile, risk-taking

### Step3: Contrast Type vs Role

The critical insight: **what type does the SITUATION require vs what type is PRESENT?**

| Crisis Type | Required Type | Wrong Type |
|-------------|--------------|------------|
| Financial collapse | ISTJ (stabilizer) | ENTP (disruptor) |
| Existential strategic crisis | INTJ (architect) | ISTJ (guardian) |
| Leadership vacuum | ENTJ (commander) | ISFJ (defender) |
| Innovation needed | ENTP (debater) | ESTJ (executive) |
| Cultural transformation | ENFJ (prophet) | ISTJ (logistician) |

### Step4: The "Wrong Type" Diagnosis

When you identify "wrong type, wrong seat, wrong time":

1. State the ACTUAL type (what they are)
2. State the REQUIRED type (what the situation needs)
3. Explain the GAP (what the wrong type cannot do)
4. Note: this is a SYSTEM failure, not an individual failure

The institution chose a guardian when it needed an architect. That is not the guardian's fault.

## Common Mistakes

- Do NOT use MBTI as insult. It is analytical, not judgmental.
- Do NOT assume type = intelligence. ISTJs can be brilliant in their domain.
- DO identify the DOMAIN of competence (where the type excels) vs DOMAIN OF FAILURE (where the type is blind).
- DO note that crisis CEOs are often installed for financial stabilization, not strategic transformation — the institution WANTED an ISTJ, they just chose wrong for the long term.
