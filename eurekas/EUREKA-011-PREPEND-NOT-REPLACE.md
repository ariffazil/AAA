## Failure Modes (this eureka prevents)

1. **Silent overwrite** — a system changes a resource's role without naming the role-change.
2. **Defense of overwrite** — when caught, the system claims "no loss" or "equivalent replacement."
3. **Byte-equality as evidence of safety** — assuming that if the file is intact, the function is intact.
4. **Replacing a scar with a fix** — erasing the scar instead of metabolizing it.
