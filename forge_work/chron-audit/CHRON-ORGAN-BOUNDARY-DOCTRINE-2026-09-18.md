## 3. CHRON ↔ Each Organ

### arifOS ↔ CHRON

| arifOS | CHRON |
|--------|-------|
| May this happen? | What happened? |
| Who has authority? | When? |
| What transitions are legal? | What changed? |
| | What was believed then? |
| | What was corrected later? |
| **= law** | **= history** |
| Governs transitions | Governs temporal context |

### arifFlow ↔ CHRON

| arifFlow | CHRON |
|----------|-------|
| publishes | interprets |
| time as sequence | time as meaning |
| receipts, cycles, telemetry, events | episodes, predictions, verification, learning |

**One rule:** CHRON depends on arifFlow evidence. arifFlow must not depend on CHRON interpretation.

### FRAME ↔ CHRON

| FRAME | CHRON |
|-------|-------|
| witnesses | narrates |
| "CHRON is wrong." (independent) | "Here's what happened." (narrative) |

FRAME must be able to say CHRON is wrong without asking CHRON's permission. No control may certify itself.

### HERMES ↔ CHRON

| HERMES | CHRON |
|--------|-------|
| chronology | semantics |
| Event A before Event B | Why it matters, how it should be interpreted |

CHRON knows the sequence. HERMES knows the meaning.

### WELL ↔ CHRON

| WELL | CHRON |
|------|-------|
| owns health evidence | owns temporal lineage |
| sleep, energy, body check, fatigue, health events | what happened, when, outcome, trend |

WELL is a reality source. CHRON is not the owner of human reality.

### WEALTH ↔ CHRON

| WEALTH | CHRON |
|--------|-------|
| cash flow, assets, expenses, opportunities | expectation vs outcome through time |
| Computes the number | Tracks whether the number matched the prediction |

Example: "Fuel prices likely rise by Q4" → CHRON prediction. Actual price → WEALTH data. Verification → CHRON.

### GEOX ↔ CHRON

| GEOX | CHRON |
|------|-------|
| places, projects, wells, fields, geospatial reality | episodes, timelines, changes, consequences |
| "Bekok Deep-1 belongs to GEOX" | "What was believed before Bekok? What changed after? What lessons survived?" |

### AAA ↔ CHRON

| AAA | CHRON |
|-----|-------|
| chooses | provides temporal evidence |
| "What path should we take?" | "Historical consequences of previous paths." |

AAA is the primary consumer of CHRON temporal evidence.

### A-FORGE ↔ CHRON

| A-FORGE | CHRON |
|---------|-------|
| creates experience | metabolizes experience |
| creates scars | remembers which scars mattered |

Every execution becomes: action → outcome → episode. That's CHRON's raw material.
